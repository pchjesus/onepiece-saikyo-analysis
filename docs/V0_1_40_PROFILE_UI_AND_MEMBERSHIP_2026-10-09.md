## 적용 항목

| 사용자 요청 | 반영 위치 | 동작/원칙 |
|---|---|---|
| 1. 패기 장문 축소 | `CombatProfile.tsx`, `styles.css` | 무장색·견문색·패왕색에는 상태와 `?`만 먼저 표시. 별도 클릭 시 보유 설명, 패휘감 상태, 실제 특출난 응용/강한 추론, 적용 시점, 불확실성과 자동 가산 없음 표시. 컴포넌트 바깥 `pointerdown`, Escape에 팝업 닫기. |
| 2. 집단/대장 개성 | `CharacterIdentity.tsx`, `CharacterPage.tsx` | 선택한 인물 창의 왼쪽 가는 강조선과 27px 소속 아이콘. 흰수염은 초승달 콧수염 해골·뼈 모티프를 직접 그린 간단 SVG(공식 로고 파일을 복사한 것은 아님). 다른 집단은 구별되는 장식 기호, 대장은 아카이누 적·아오키지 청·키자루 황·후지토라 자·료쿠규 녹을 낮은 채도로 반영. |
| 3. 전체 UI 색감 | **미적용**, `UI_COLOR_PALETTE_OPTIONS_2026-10-09.md` | 사용자 컨펌 전에는 배경·상단 헤더·전체 탭·모달 등의 전역 색을 바꾸지 않음. A 항해 지도 / B 선명한 모험 / C 야간 대항해. |
| 4. 열매 각성 | `SpecialCombatTrait.awakening?: 'confirmed'`, `CombatProfile` | 로·도플라밍고·카타쿠리·루치·카쿠의 **확인된** 열매에만 `열매 각성자` 배지. 전투 방식의 중복된 `각성~` 태그 제거. 상디 신체 개조 각성은 악마의 열매 각성이 아니므로 배지 없음. |
| 5. 겹치는 전투 방식 | `characters.ts` | 상디 `스카이워크`만 보존하고 `공중전` 태그 제거, 조로 일반 `근접 검술`, 미호크 `근접 검격`, 비스타 일반 `근접 검격`, 바제스 중복 타격 설명 등 대표 태그로 축약. |
| 6. 미호크 ‘강자 요격’ | `characters.ts` | 정상결전에서 루피를 저지한 사실은 맞지만 `강자 요격`은 공식 기술이나 독립 기계적 전투 방식이 아닌 *교전 목적* 설명. 기술 목록에서 제거. 원작 전투 근거와 평가에는 개입 없음. |
| 7. 해적단 안 인원 정렬 | `getCharacterList.ts` | 선장(및 제독) → 부선장 → `1번대/1번선` 등 명시된 번호순 → **공식 서열 동률/불명인 경우 한국어 이름순**. 록스/로저/뉴게이트/카이도/링링/티치는 소속의 선장으로 맨 앞. 백수 대간판, 빅 맘 3장성은 전투력이나 숫자로 임의 서열을 만들어 정렬하지 않음. 해군은 원수 → 대장 → 중장, 혁명군은 참모총장 → 군대장. |
| 8. 현재 소속 | `characters.ts`, `memberships.ts`, `getUniqueCharacterList.ts` | 쿠잔의 대표 Group을 **검은 수염 해적단**으로 변경, 10번선 선장 현 소속 추가, 해군은 과거 대장 소속으로 유지. 검색·랭킹의 대표 Group은 현 소속을 우선하고 한 인물이 중복 계산되지 않도록 함. |
| 9. 뉴게이트의 마지막 소속 | `CharacterPage.tsx`, `App.tsx` | 흰수염 해적단에서는 이미 사망한 선장의 마지막 소속을 `과거 소속`이라 표시하지 않음. 다만 록스 해적단은 실제 과거 소속이므로 표시 유지. Membership의 역사적 상태 기록과 사망 당시점은 삭제하지 않음. |
| 10. 징베 전 칠무해 | `memberships.ts` | 칠무해 그룹에 `former` Membership 추가, 밀짚모자 일당 현 소속 유지. 칠무해 탭은 과거 소속으로 표시, 랭킹·검색에서는 밀짚모자 소속이 대표. |

## 데이터·영향 경계

- `CombatProfile` 도움말은 텍스트 노출 위치만 바꾸므로 예외적 패기 정성평가 `excellenceAssessments`의 **원문과 결론은 보존**.
- `SpecialCombatTrait.awakening`은 점수 데이터가 아닌 명시적 확인 메타데이터. 7개 평가 스탯·패기 원점수·캐릭터 성장치를 자동 증감하지 않는다.
- `Character.crewId`에서 쿠잔의 대표 Group이 바뀌며, 2개 Membership 추가(47→49), 전체 인물 43·평가 45·315축 그대로. `getCharacterList`만 순서를 새로 정의하고 `getUniqueCharacterList`에서는 현재 소속을 우선한다.
- 로저/뉴게이트의 역사적 상태를 UI에서 '현재 살아 있는' 것으로 바꾸지 않는다.
- 글로벌 테마 3번은 오직 컨펌용 시안 문서에만 존재한다.
