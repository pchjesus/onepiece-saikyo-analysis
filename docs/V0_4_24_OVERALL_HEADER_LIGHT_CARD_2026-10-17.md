# v0.4.24 — Overall 종합 전투력 카드 헤더 이동

## 목표와 사용자 의도
기존 일반 캐릭터 상세 페이지의 어두운 종합점수 독립 카드가 화면 공간을 차지한다. 캐릭터의 큰 이름 우측 영역에 이동하고 백색 기반 사이트에 맞는 밝은 청회색으로 개선한다. 기존 기능을 보존하고 해석상 불필요한 안내문은 추가하지 않는다.

## 구현/시각 디자인
- 오직 일반 `CharacterPage`의 공통 `.detail-heading` 안에 기존 Overall 점수·원래 동일 버튼(랭킹으로 열기)·`?` 계산 설명을 옮긴다. 두 개 표시하지 않는다.
- 헤더 이미지+이름+이명/칭호+상태 선택과 같은 레벨의 오른쪽에 폭 188~230px 소형 카드. 하단 CharacterQuote는 전체 너비로 유지한다.
- 배경은 흰색과 조화되는 연한 청회색(#f9faf9와 기존 identity accent 7% 혼합); 텍스트 짙은 청회색(#253746), 테두리 미묘한 회청색, 얇은 4px 소속색 스트라이프를 사용. 검은색 풀필 카드 사용하지 않는다.
- 소속색은 `characterIdentityStyle`의 `--identity-accent`만 사용하며 새 하드코딩 소속 테이블을 만들지 않는다.
- mobile <=760px에서 헤더 프로필/카드 순차 wrap, 카드 우측 정렬. <=380px에서 전체폭 카드로 변경, 클릭·확대 가능. 모든 레이아웃은 CSS, JS 상태 변환 없음.
- 도움말 `details/summary`는 버튼 외부 카드 위에 별도 배치, 내부 내용은 기존 그대로이며 사용자 설정을 바꾸지 않는다. `role`/aria/키보드 포커스 유지.
- 7축 가로 막대는 `.score-overview` 안에 그대로, 우측 전투 프로필·전투/근거 탭·차를로스 밈 페이지 무변경.
