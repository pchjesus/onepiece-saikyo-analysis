## 영향과 무결성

변경 전후 모든 616 Final·Base·Raw·readiness와 88 Overall이 동일하다. 실제 getStatRanking의 기본 상태와 최고 Overall 상태에서 8종 순위 전체를 기준 결과와 대조한다. 차를로스 포함 Overall 83명과 정규 축별 82명을 포함하며, 공동 순위와 소수점 원값을 보존한다. 18개 Matchup 원본·허브·캐릭터별 상태 조회 결과도 기준 결과와 대조한다. 매치업은 근거 기반 정성 분석이며 Overall로 자동 승률을 만들지 않는다.

원천 데이터와 실제 조회 결과 전체는 SHA-256으로 고정하여 비교한다. 원천은 기준 커밋의 저장소 코드로 재현할 수 있다. JSON axes의 evaluationId/stat 및 evidenceIds를 현행 Evaluation의 rationale, Evidence의 fact/interpretation/uncertainty, Battle의 전투 조건에 연결할 수 있다. rankings의 열 순서는 rankingColumns에 명시했으며 기본/최고상태 모드의 전후 동일 점수·순위를 모두 기록했다. 역사적 v0.3.3 및 이전 원본은 기존 회귀검증 대상으로 보존한다.

기존 구조 검증은 오류 0개, 경고 13개다. 8개 중복 현재 소속은 토비롯포·해군·SWORD 같은 조직 포함 관계다. 직접 연결 근거가 없는 5축은 샹크스 Stamina, 아라마키 Speed, 버기 Speed, 우솝 Defense/Stamina이며 모두 정량 보류했다. 경고를 숨기거나 낮은 점수로 자동 보정하지 않는다.

기존 설명 속 비교 상대 숫자는 작성 당시 revision의 값인 경우가 있다. 에이스 Attack 근거의 비스타82·잭79·크래커75 등은 현행83·80·78과 다르다. 이번 비교는 현행 Evaluation을 사용했다. 역사적 설명의 수치를 현행 앵커로 재사용하지 않는다. 이 불일치만으로 에이스79의 이동 폭을 결정할 수 없어 작업값을 유지한다.

리팩터링은 보류한다. 오버레이와 감사 데이터 조립 경로의 중복은 확인했지만 이번 판정의 계산·저장 오류는 재현되지 않았다. 실제 저장소와 감사 범위의 동일성 테스트를 추가해 누락을 탐지하며, 구조 변경은 현재 마일스톤에 필요하지 않다.

브라우저 자동화는 실제 검색 결과의 listitem·상세 tab·화면 이동 aria-label을 사용했다. 초기 탐색에서 표시 문자열을 button 이름으로 가정한 선택자가 실패했으며 접근성 역할과 이름을 확인한 뒤 전체 흐름을 다시 실행해 통과했다. 제품 코드를 수정하지 않았다. 페이지 JavaScript 오류는 두 화면 크기 모두 0건이다.

Vite는 기존 500kB 초과 청크 경고 1건을 출력한다. 프로덕션 JS/CSS 파일명과 크기는 기준 빌드와 동일하다. 이번 검토 JSON과 테스트는 앱 번들에 포함되지 않는다. 빌드가 생성한 tsconfig.app.tsbuildinfo는 작업 트리에서 정리했다. 원작 컷 직접 검증·실기기 수용·외부 배포는 이번 자동 테스트 결과로 인증하지 않는다.
