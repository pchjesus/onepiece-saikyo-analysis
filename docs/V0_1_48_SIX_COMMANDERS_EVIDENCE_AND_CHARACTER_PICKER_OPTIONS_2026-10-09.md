### 죠즈 — 방어 84, 직접 참격 차단 우위

- 확인 사실: 공식 TV 463화에 미호크가 흰수염에게 날린 큰 참격을 다이아몬드화한 몸으로 차단. TV 476화에서는 쿠잔에게 개입. 공식 뉴스에서도 쿠잔과 싸운 흰수염 3번대장임을 언급.
- 전투 조건: 해당 참격이 미호크의 최고 출력이었는지는 불명확. 쿠잔 빙결은 물리 절단에 대한 내성과 별개의 대응 영역.
- 해석: 현재 방어84는 잭/카타쿠리와 동일하나 각각 신체 내구·회피·다이아 방어라는 다른 경로. 원작 관련 패널 추가 대조 시 방어 85~86이 가능한 검토 범위지만 수치 확정 아님.
- 권고: 방어 상승 후보 검토. 기술74·범용성74는 방어 특화와 역할 폭 분리 유지.

### 비스타 — 기술 87, 공격 82 유지가 우선

- 확인 사실: 공식 인물 소개에서 비스타는 세계 최강 검사 미호크와 호각의 검술 공방을 할 정도의 이도류 대검호라고 명시.
- 조건: 단기 검술 공방 성립이 종합 전투력·장기전 지속력까지 미호크와 동급이라는 의미는 아님.
- 해석: 기술87은 카타쿠리87과 같아도 다른 메커니즘의 기술 특화로 합당. 속도80·공격82, 범용성74의 편차도 설명 가능.
- 권고: 현 점수 유지. 지구력77과 Combat IQ77의 독립 반복 근거 부족을 별도 불확실성으로 관리.

### 퀸 — 범용성 80 상향 검토 우선

- 확인 사실: 공식 1053화 브라키오사우루스 분리 구속과 1061화 제르마 능력 재현·은신·과학 무장. 상디의 외골격과 고속 대응, 퀸이 오소메에게 주의가 분산된 조건도 확인.
- 해석: 근접 고대종·구속·광선·전격·투명화가 서로 다른 전투 역할을 수행하므로 Versatility80은 상대적으로 낮게 책정됐을 여지가 큼. 82~83은 원작 추가 검토의 후보 범위. 숙련79은 여러 기계 장비 보유와 실전 정밀 사용을 구분한 수치이며 Combat IQ74는 전투 중 판단 실수와 기술 지식을 분리해야 함.
- 권고: 범용성 80→82~83 재검토 후보. 자동 적용 금지.

### 크래커 — 명확한 근거 문장과 실제 값 불일치

- 현재 공격 Base75 + 승인된 Armament Raw4×0.5 = Final77인데 원본 평가 문장은 Final74라고 작성되어 있다.
- 현재 방어 Final81인데 원본 평가 문장은 76으로 제한했다고 작성되어 있다.
- 이는 해석 차이가 아니라 실제 평가값과 사용자에게 제공되는 근거 설명 사이의 데이터 무결성 결함이다. 수치·근거 판단 후 문장을 77/81로 수정하거나 점수를 재검토해야 함.
- 공식 TV 799화 갑옷 속 본체와 비스킷 병사 공개, 805화 나미의 비·루피의 병사 먹기, 806화 Tankman에 패하는 상황 대조. 방어 시스템은 본체 맷집과 구별, 오랜 비스킷 공급은 본체가 같은 피해를 견딘 기록이 아님.
- 권고: P0 설명/실제 수치 일치 패치. 근거상 방어81을 유지할지 직접 패널 확인 후 결정. 현재 7축 숫자는 변경하지 않음.

### 스무디 — 개인 대상 유효타 표본 부족

- 공식 프로필은 스위트 3장성과 착즙 능력 확인. 공식 TV 868화는 수분 흡수 거대화·거대한 원거리 참격 반복과 나미/징베의 써니호 회피를 기록.
- 사실로는 공격 규모와 범위가 확인되나 고위 개인 상대 실제 적중·방어·지구력·속도는 직접 확인되지 않음.
- Attack76 상향 가능성은 있지만 고위 강자에게 실제 유효타가 없으므로 지금 수치 확정 어려움. Speed74·Defense75·Stamina76은 약함 확정이 아닌 근거 부족 Draft.
- 권고: E3 근거 충분도 표시 보강, 점수 조정 보류.

### 시류 — 기습 성공과 패기 Raw 2 직접 확인 문제

- 공식 프로필은 투명 열매와 이전 임펠다운 간수장 경력, TV 1121화는 가짜 구조 요청·코비에게 투명 기습·가프의 보호 개입 및 관통을 기록.
- 가프가 몸을 대신 넣은 결과를 정면에서 가프 방어를 돌파한 단독 화력으로 환산하면 안 됨. Combat IQ78은 보호 대상 선택의 전술 판단으로 가능하지만 반복 표본 부족.
- 현재 Technique Final78=Base77 + Armament Raw2×0.5. 기존 Evidence(Manga 1087 참조)는 무장색 사용을 확정처럼 기록했으나 공식 TV 줄거리에는 무장색 사용이 명시되지 않음. 만화 원문 검격 부분에서 무장색 적용의 독립적인 확인이 필요. 공식 TV 미기재가 곧 미사용을 뜻하는 것도 아님.
- 권고: Raw 2를 함부로 삭제하거나 확정하지 말고, 만화 1087 페이지 직접 감수. Technique/Combat IQ E3 보강 검토.

## 2. 합산 서열과 개별 강점의 구분

- 죠즈 방어84, 비스타 숙련87, 퀸 다양한 독립 과학 능력, 크래커 외장 갑옷/다수 병사, 스무디 대형 참격, 시류 은신 기습은 각각 다른 축을 강조한다.
- 상위 사최간 전체 Overall이 더 높더라도 특정 항목에서는 하위 사최간이 앞설 수 있다. 특정 직책에 대한 일괄 공격·방어·숙련 상한이나 +N 보너스는 도입하지 않는다.
- **즉시 정합성 개선 우선순위** 크래커 설명 오기 > 시류 무장색 적용 재대조 > 퀸 범용성·죠즈 방어 근거 심화 > 스무디 개별 교전 자료 보강 > 비스타 현 수치 유지.

## 3. 현재 인물 선택 UI 진단

현재 59 unique Character/73 Membership/약 23 Group 정의. App.tsx는 '가로 스크롤 그룹 탭' → '가로 스크롤 그룹 캐릭터 칩'의 두 줄이며 그룹 전환 시 첫 캐릭터를 자동 선택한다. 모바일에서는 숨은 그룹/선택 대상을 찾는 조작이 늘어날 수 있다.

이미 CharacterSearch.tsx는 이름·이명·소속 검색, 전각/공백 정규화, 8건 자동 완성, 키보드 방향키/Enter/Escape, 외부 클릭 닫힘, 캐릭터 ID deduplication을 지원한다. Matching/Rankings은 고유 캐릭터, Group navigation은 Membership-expanded라는 PROJECT_SPEC §13.1의 원칙을 유지해야 한다.

MatchupHome.tsx는 양쪽 선수별 59명 native select, 양쪽 별도 Evaluation 시점, 선수 교체/랜덤/추천 대진을 갖췄다. 선택기 개선으로 동일 캐릭터끼리 매치업 허용 또는 시점/소속/랭킹 중복 발생시키면 안 된다.

NN/g는 많은 탭이 오버플로 목록에서 숨을수록 발견 가능성이 낮아진다고 설명한다. W3C WAI-ARIA combobox는 검색형 선택 UI의 포커스·키보드·닫힘 규칙을 제공한다.

|---|---|---|---|
| A. 기존 탭 + 스크롤/더보기 | 그룹 탭과 캐릭터 칩 두 줄 유지. 좌우 화살표, 더보기 목록, 선택 자동 스크롤, 기존 검색 강조 | 가장 작은 수정, 현재 화면 거의 보존 | 100명/그룹 수 증가 시 이중 가로 스크롤의 근본 문제 잔존 |
| **B. 추천: 그룹 선택 dropdown + 그룹 내 칩 + 전체 인물 검색 팝업** | 선택 그룹 1칸, 현재 그룹 기존 칩 보존. 전체 찾아보기로 이름/이명/소속 검색, 그룹 필터, 현/과거 소속 표시. 모바일 화면형 시트/대화창 | 익숙한 빠른 선택과 대량 검색의 확장성 양립, 기존 Search와 getCharacterList 재사용 | 팝업 포커스, 모바일 닫힘·뒤로가기, 검색/그룹 상태 동기화 테스트 필요 |
