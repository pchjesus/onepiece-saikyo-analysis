## 1. 이번 단계에서 바꾸는 것 / 바꾸지 않는 것

바꾸는 것:
- 기존 24인의 Final Core Stat을 동일 기준으로 재검토한다.
- 트라팔가 로 / 돈키호테 도플라밍고 / 보아 핸콕을 전 칠무해 그룹의 평가 로스터에 추가한다.
- 신규 3인의 전투·Canon Evidence를 별도 구조화한다.
- Prime Garp에 Ch.1165 God Valley 직접 전투 Evidence를 추가하고 패왕색 보유·고급 적용 상태를 갱신한다.
- 향후 Matchup 분석을 위한 비수치 Evidence-aware 도메인 기반을 추가한다.

바꾸지 않는 것:
- 7개 Core Stat의 종류.
- Balanced 1.2의 7개 Final 단순평균.
- Haki Weight 0.5.
- Special Combat Profile을 Overall에 직접 합산하지 않는 원칙.
- Overall을 1대1 승률로 해석하지 않는 원칙.

## 3. 재보정 기준

- 직책이나 현상금을 점수로 변환하지 않는다.
- 현재 로스터의 순위에 맞추기 위해 점수를 역산하지 않는다.
- 같은 Canon 사건을 여러 Stat에 연결할 수는 있지만 서로 다른 평가 의미가 있어야 한다.
- Attack은 파괴 규모보다 실제 유효 피해·방어 돌파·반복성을 우선한다.
- Defense는 차단·회피·피해 감소를, Stamina는 피로·누적 피해 이후 전투 지속을 평가한다.
- Technique는 능력/무기 운용의 정밀성과 완성도, Combat IQ는 무엇을 언제 선택했는지, Versatility는 실제로 검증된 역할·거리·상황 전환 폭을 평가한다.
- 동일 시점에 양립할 수 없는 Peak 상태는 동시에 상시 성능처럼 합성하지 않는다.
- Prime은 확인 가능한 하나의 최고 전투 상태를 기준으로 하고, 과거/현재 장면의 단순 합성은 피한다.

## 4. 신규 칠무해 해석

### 트라팔가 로
- 빅맘에게 실제 내부 손상·골절을 만든 각성 성과를 Attack에 반영한다.
- Puncture Wille의 지형 규모를 일반 대인 결정력으로 그대로 환산하지 않는다.
- ROOM 위치교환과 대응 수단을 Defense에 반영하지만 순수 Speed와 구분한다.
- Ch.1063의 능력 해제는 강한 Haki의 실전 상호작용 근거이나 Haki 유형은 원작이 특정하지 않으므로 typed Raw Contribution을 만들지 않는다.
- Technique / Combat IQ / Versatility가 높은 능력형 상위 전투원으로 평가한다.

### 돈키호테 도플라밍고
- Dressrosa Law의 팔 절단과 실 공격의 직접 피해는 인정한다.
- Gamma Knife 이후 내부 봉합은 Technique·Stamina·위기 판단의 근거로 분리한다.
- 각성은 Technique의 강한 근거다.
- Birdcage는 전장 통제·활용 폭의 근거지만 개인 Attack이나 후지토라보다 높은 전투력의 증거로 사용하지 않는다.
- Gear 4에게 보인 정면 공방 열세를 일최간 앵커와의 핵심 제한 근거로 남긴다.

### 보아 핸콕
- Haki 체술과 Mero Mero의 다수 제압은 실제 공격 성과다.
- 석화의 높은 치명성은 Core Stat만으로 모두 표현하지 않고 향후 Matchup의 Special Win Condition으로 분리한다.
- 상위권 장시간 정면전 표본이 부족하므로 Defense / Stamina / Combat IQ는 보수적인 Draft를 유지한다.
- Versatility는 석화의 근·원거리 적용 폭을 인정하되 단일 열매 메커니즘의 기술 수를 독립 능력 여러 개처럼 합산하지 않는다.

## 5. Haki 정책

현 단계에서 Haki Weight는 0.5로 유지한다.

이유:
- Raw Haki는 Haki의 절대 등급이 아니라 해당 Stat에서 확인된 실제 Application을 추적하기 위한 값이다.
- Evidence가 많이 묘사된 캐릭터와 적게 묘사된 캐릭터의 Raw 총량 차이를 그대로 패기 실력 차이로 볼 수 없다.
- Haki의 중요한 효과 중 일부는 가산점보다 '공격 가능 여부 / 능력 효과 해제 / 방어 상호작용'처럼 Matchup 조건으로 작동한다.

신규 칠무해 3인은 typed Haki Application을 직접 특정할 근거가 구조화되기 전까지 Raw 0을 유지한다. Capability confirmed와 Raw Contribution 0은 모순이 아니다.

## 6. Prime Garp 갱신

기존 데이터는 Prime 수치를 평가하면서 직접 세부 Evidence가 노년 Hachinosu에 크게 의존했다.

Ch.1165에서:
- Prime Garp와 Roger가 Rocks를 상대로 직접 최고 수준 Haki 공방을 수행한다.
- Supreme King Haki 사용이 명시적으로 확인된다.
- 최종 결과는 Garp+Roger 공동전이므로 개인 단독 승리나 단독 결정력으로 변환하지 않는다.

따라서 Garp의 Conqueror capability와 infusion 상태는 confirmed로 갱신하되, 공동 공격을 중복 점수화하지 않는다.
