# 다음 캐릭터 집단 확장 브리핑 — v0.1.28 결정 반영

> **다음 신규 집단은 크로스 길드로 확정.** 이 문서는 다음 조사 순서와 검증 기준을 고정하며, 아직 미호크·크로커다일·버기의 새 능력치나 Evaluation을 생성하지 않는다. 개별 점수는 Canon 분석·점수안 제시·사용자 확인 후 반영한다.

## 1. 저장소 현재 상태

- UI 평가 로스터는 8개 집단·27 Character이며, 몽키 D. 가프의 전성기/현재 분리로 Evaluation은 28개다. 그룹 탭은 `sampleMemberships`에서 만들어지며 `sampleGroups` 등록만으로 표시되지는 않는다.
- 지금 코드의 등록 그룹 중 **왕의 부하 칠무해(`seven-warlords`)**, **크로스 길드(`cross-guild`)**, **혁명군(`revolutionary-army`)**, **로저 해적단(`roger-pirates`)**, **록스 해적단(`rocks-pirates`)** 등이 앞으로 확장 가능하다.
- 이미 소속 중인 흰수염 해적단·빨간 머리 해적단도 추가 캐릭터를 검토할 수 있다.
- **주의:** 현 `sampleCharacters`에 등록하면 7축 Evaluation이 반드시 연결되어야 현재 UI가 안전하게 동작한다. 원작 Evidence가 부족한 E3 후보를 점수 없이 표시하려면 Master Pool/평가 로스터 분리 UX가 먼저 필요하다.

## 3. 우선 개발 방식

1. 사용자에게 **추가할 집단과 후보 1명**을 먼저 컨펌 받는다.
2. 해당 캐릭터의 원작 장면을 **직접 관찰 사실 / 당시 조건 / 해석 / 관련 스탯 역할 / Haki Application**으로 나눈다.
3. **E1/E2/E3 준비도**를 평가한 뒤 E1/E2에 한해 7 Core Final+Base/Raw 근거를 별도 점수안으로 제시한다. 정보 부족은 E3 미평가 처리로 제안한다.
4. 기존 27명과 공격·방어·지구력·속도·기술·전투 지능·범용성 점수 앵커를 비교한다.
5. **개별 캐릭터 점수와 근거를 사용자에게 확인받은 뒤** 데이터·계산 테스트·UI에 반영한다.
