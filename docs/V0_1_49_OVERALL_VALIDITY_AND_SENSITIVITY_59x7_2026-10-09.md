# v0.1.49 — Balanced Overall 타당성·민감도 진단 (59명 × 7축)

> **감사 보고서, 공식 평가 모델 변경 아님.** 기준 코드 `main@ee48392a74a645258d0bbf5475467711a6dfe883` (v0.1.48), 2026-10-09. 실험 가중치는 진실이나 신규 공식 모델이 아니라 **의도적으로 차이를 크게 드러내는 민감도 스트레스 테스트**다. 59명은 임의로 선발된 강자 중심 표본이며 전 세계 등장인물의 통계표본이 아니다.

## 1. 현행 계산 모델과 서로 다른 '신뢰'의 의미

`PROJECT_SPEC.md` §4, §4.1, §10과 실제 `src/domain/calculation/calculateCombatPower.ts`/ `src/domain/evaluation/score.ts` 검증:

```text
FinalStat_i = min(100, BaseStat_i + HakiRaw_i × 0.5)
Balanced Overall = (A + D + Stamina + Speed + Technique + CombatIQ + Versatility) / 7
```

- **계산의 재현성:** 주어진 원자료와 동일한 모델 버전이면 결과가 항상 같아 신뢰할 수 있다(산술·코드 차원).
- **점수 평가의 측정 신뢰도:** 독립 평가자 일치도/동일 장면 재채점 일치도/교차 평가 보정 지표가 아직 측정되지 않아 **판단 보류**.
- **개념 타당성:** 공격 1점과 전투 지능 1점을 동일 간격·동일 전투 성능 기여로 취급할 경험적 근거가 없다. 7개 전문능력의 0~100점은 공통 수치 범위이지만 실전에서 **서로 교환 가능한 단위라는 보증이 없다**.
- **승부 예측 타당성:** 특정 1v1의 승패·피해·시점·지형·능력의 비선형 상성을 독립 참조 결과와 비교해 예측력을 실증한 테스트는 아직 없다. 기존 15개 직접 Matchup은 **승자 정답 라벨 15개**가 아니라 `advantage/conditional/unknown`으로 나뉜 개별 상성 근거 기록이다. 이를 정확도 산정에 오용하지 않는다.
- **핵심 주의:** Attack90 vs Defense89는 1점 차이의 피해 관통을 뜻하지 않으며, 동일 축의 Attack90 vs Attack80조차 피해량 12.5% 증가를 뜻하지 않는다.

## 2. 413개 대표 최종 스탯의 근거 메타데이터 현황

- 총 59개 대표 평가 × 7축 = **413개**. 과거 평가 시점 등 중복 Evaluation 3개를 포함하면 기존 데이터 **62 Evaluation / 434 Stat**.
- 현재 대표 스탯 Evidence-readiness 태그: **E1 29개 / E2 131개 / E3 61개 / 미입력 192개**.
- 정보가 등록된 축은 **221/413 = 53.5%**. 미입력은 **'약하다' 혹은 'E3'라고 임의 추정할 수 없다**. 따라서 같은 Overall에도 근거 충분도가 다를 수 있고, '전체 평가 신뢰도 xx%'라는 정확성/승률 수치로 환산할 수 없다.
- E1·E2·E3는 **근거 충분도 계층**, 확률·오차구간·가중치·캐릭터 전투력 보너스가 아님.
- 기초 캐릭터/소속/전투·Evidence/스탯 데이터 구조를 보존하고, 누락된 readiness의 확대 감사와 점수 기준의 작성은 **별도 데이터 품질 작업**으로 계획해야 한다.

## 6. 실제 승부 근거와 모델 간 검증이 아직 안 되는 이유

현재 Matchup 15개는 각기 조건/구간별 `character-a`, `character-b`, `conditional`, `unknown` 등의 Evidence 근거를 저장한 모음이며, 독립된 **중립 1대1 판정 정답 15건**이 아니다. 실제 원작 승패 역시 팀전·중상·기습·외부 개입·능력 상극을 충분히 분리해야 한다. 따라서 다음은 **아직 산출할 수 없다**:

- 평균 Overall로 중립 1대1 승률을 얼마나 맞히는지(%)
- 85점이 80점 대비 어느 정도 실전 우위 확률을 갖는지
- 7축 동일 가중치가 다른 모델보다 더 정확하다는 통계적 검증
- E1/E2/E3가 점수의 95% 신뢰구간이나 ±몇 점의 오차를 의미한다는 주장

통계적 검증을 하려면 **독립적으로 확인 가능한 승부 표본**과 교전 구조/상태/자원/외부 개입 태그, 예측 문제의 명확한 정의가 선행되어야 한다. 전투 결과만으로 피해량/방어/속도와 같은 7축 기본값을 다시 정하면 결과를 설명 변수와 검증 라벨에 **중복 사용한 순환 검증(데이터 누수)**이 발생한다. 학습/평가 사건을 분리해야 한다.
