# v0.1.40 후속 제안 — 전체 UI 원피스풍 색감 (승인 전 / 미적용)

**목적:** 이미 적용된 캐릭터 프로필의 국소 테마 장식과 별개로, 앱 전체의 배경·카드·강조·탭 색을 변경할지 사용자에게 시안으로 확인받는다.

**상태:** 검토 문서만 추가. 글로벌 CSS `:root`, 랭킹, 매치업 전역 테마 **변경 안 함**. 색상들은 디자인 제안이며 작품의 공식 지정 컬러가 아니다.

| 안 | 이름 | 배경 | 카드 | 헤더·글자 | 강조·버튼 | 보조 강조 |
|---|---|---|---|---|---|---|
| A | 항해 지도 · 양피지 | `#F8F4E8` | `#FFFEFA` | `#19344C` | `#B14A42` | `#D3A35E` |
| B | 모험의 선명함 | `#F3F7F6` | `#FFFFFF` | `#19465A` | `#D85B45` | `#D4A747` |
| C | 야간 대항해 | `#152536` | `#1E3448` | `#F5F1E7` | `#E3B75B` | `#7CA9B5` |

- **A (추천):** 현행 밝은 UI를 유지하면서 바다 남색·연한 양피지·적갈색·금빛 한두 곳만 활용. 스탯 수치의 읽기성과 기존 컴포넌트 구조를 최대한 유지하는 낮은 위험.
- **B:** 캐릭터의 활기찬 모험 인상을 주지만 지금보다 강조색 면적이 커질 수 있어 선택상태/위험색 대비와 스탯 탭 계층의 검증이 중요.
- **C:** 분위기 변화가 가장 크지만 랭킹·Evidence·Modal·Chart의 표준/강조 텍스트 전부 명암 검사가 필요함. 구조적 작업량↑.

## 적용 전에 확인해야 할 UX

1. 전체 탭, 캐릭터 칩 선택, FEATURED 매치업 선택, 패기 도움말·모달의 키보드 focus 링이 명확할 것.
2. 100점/0점 및 E1–E3의 색상이나 캐릭터 인상색이 스탯 크기·근거 충분도와 혼동되지 않을 것.
3. 모바일과 큰 글씨 모드에서 배경/카드/버튼 텍스트 대비 확인.
4. 접근성 WCAG 4.5:1 수준의 본문 대비 검토 후 적용. 실제 기기 검증 전 성공으로 표현 금지.

**사용자에게 A/B/C 중 선택받은 뒤** 별도 PR에서 구현·회귀 검증한다.
