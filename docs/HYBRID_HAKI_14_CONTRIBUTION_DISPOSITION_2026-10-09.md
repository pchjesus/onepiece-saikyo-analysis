2. **Interpretation:** 미래예지의 정보 우위와 미래예지에 기반한 회피는 상호작용하지만, *같은 회피 1번을 Defense·Technique·Combat IQ의 독립 최고점 3개로 환산하는 행위*는 보장되지 않는다. 미호크의 흑도는 최상위 무장색 숙련에 대한 강한 **추론**이지 영구 흑도를 직접 만든 법칙이나 Raw +N의 공식 근거가 아니다.

4. **Calculated preview:** 네 건을 이관해 현재 사용 중인 Weight 0.5를 유지하면 **모든 39개 Evaluation과 273개 Stat의 Final/Overall은 완전히 동일**하다. **Haki Weight를 변경한 다른 모델**에서는 동일성을 보장하지 않으므로 계산 모델 및 평가 데이터 버전을 함께 심사해야 한다.

## 2. Base 이관을 제안할 수 있는 네 건

여기서 `Base_new = Base_old + Raw_moved × 0.5`, `Raw_new = Raw_old − Raw_moved`이고, Final의 현행식은 변함없이 `min(100, Base + Raw*0.5)`다. **변환은 새로운 전투력 평점이 아니라 기존 전투 성과의 분해 방식에 대한 조건부 제안**이다.

| Evaluation | Core Stat | 기존 Base / Raw → Final | 후보 Base / Raw → Final | 왜 이관 후보인가 |
|---|---|---|---|---|
| 사카즈키 | Defense | 94 / 2 → **95** | **95 / 0 → 95** | 삼대장 합동 지진파 방어: 성과는 사실이나 별도 무장색 독립 프리미엄은 확인되지 않음 |
| 쿠잔 | Attack | 91 / 4 → **93** | **93 / 0 → 93** | 가프와 Ice Glove 공격 교환: 관찰된 유효 공방을 통상 능력 Base에 통합 |
| 쿠잔 | Defense | 92 / 2 → **93** | **93 / 0 → 93** | 공동 방어를 예외적 무장색 보너스와 구별 |
| 카타쿠리 | Attack | 79 / 4 → **81** | **81 / 0 → 81** | 루피 상대 무장색 공격 성과 자체는 확인, 특별한 한계효과는 분리되지 않음 |

**총 이동 효과:** 기존 총 Typed Raw **256 → 244(후보)**; 네 Stat Base는 합계 +6점; 실제 Final은 273개 전부 그대로. 기존 **53**개 Typed Raw를 **49**개로 줄이는 후보이며, **남은 10개는 이번 단계에서 Raw가 유효하다고 승인한 것이 아니라 보류한다.**

특히 쿠잔의 Attack에 사용된 장면을 **Technique Raw +4에서도 사용**하고 있어, Attack을 Base로 이관했다고 해서 두 축의 결과 중복이 해소되는 것은 아니다. 데이터의 남은 Haki Raw는 계속 심사해야 한다.

## 5. 두 가지 다른 산식 변화의 함정

### A. Base 이관 후보 — 현재 모델 Weight 0.5

`NewBase = OldBase + OldRawMoved×0.5`, `NewRaw = OldRaw − OldRawMoved`.

**검증 대상:** 기존 점수와 동일한 후보 39 Evaluations, 273 Stats를 프로그램이 복제해 산출한다. ***실제 생산 Evaluation 객체를 덮어쓰지 않는다.***

### B. Haki Weight 0.0/1.0 등 다른 계산 모델 적용

Weight 0.5를 보존해도 이관안은 다른 Weight에서 다른 점수를 낼 수 있다.

- 예: 쿠잔 Attack +2 Base, Defense +1 Base로 이관 → Weight 0일 때 총 7축 Final합 **+3** / Weight 0.5일 때 **0** / Weight 1.0일 때 **−3**.
- 따라서 후보안이 Balanced 1.2에서 순위를 바꾸지 않았다고 **다른 모델에서도 호환됨**을 뜻하지는 않는다. 모델 버전/데이터 버전 일치와 전 모델 교차 재현 테스트가 후속 변경 승인 조건이다.
- 만약 단지 Raw를 제거하고 Base는 고정하면 결과가 떨어지지만 그것은 **정상적인 재보정 후보가 아니다.** 기존 평가가 애초부터 통상 패기를 Raw로 제외했기 때문이다.

## 6. Katakuri Evidence 업데이트 — 정보와 직접 효과를 분리

`evidence-katakuri-composure-future-sight-857`을 **공식 애니메이션 공식 줄거리 참고 Evidence**(source type `supplementary`)로 추가했다.

- **Fact:** 침착함을 잃으면 공격을 허용, 회복하면 미래 행동을 읽고 모치 신체 일부를 변형해 회피. 공식 857화 줄거리에서 직접 기술하는 사실이다.
- **Interpretation:** 이 능력은 완벽한 회피/미래예지 무적이 아니고, 실제 Defense 성과에 조건이 있다.
- **Stat mapping:** Defense=`primary`, Technique=`secondary`, Combat IQ=`context`, Speed=`context`. 하나의 결과를 여러 Stat에 독립 추가 점수로 자동 전환하지 않는다.
- Katakuri `Attack/Defense/Technique/Combat IQ`의 Readiness를 **E2**로 기록하고 해당 평가의 **evaluationDataVersion**을 `evaluation-0.1.35-haki-evidence-review-draft`로 구분했다. 7축 Base/Raw/Final은 그대로.
- 전체 Readiness 미지정: **196 → 192**, Evidence 연결이 비어 있는 Stat 수는 계속 **11**.
- 위 수정은 273개 스탯의 원작 개별 검증 완료를 의미하지 않는다.

## 7. 완성 기준과 후속 승인 게이트

이번 PR의 **실제 구현**은 오직 분석용 `previewHybridRawPilot()`, 14건의 개별 평가(판정·근거·불확실성), 테스트, 카타쿠리 보조 Evidence 및 E2 표시다. 런타임 랭킹·공식 Calculation Model·Haki Weight·기존 39 Numeric Evaluations의 수치에는 영향을 주지 않는다.

**점수 변동 없는 한정적인 Base/Raw 재분류 4건도 공식 평가 데이터로 이관하려면**, 전투 조건, 비교 캐릭터, 계산 모델 0/0.5/1.0 민감도, 평가 데이터 버전, 저장/복원과 전체 순위 영향을 검토하고 사용자에게 별도 승인받아야 한다.

**향후 실제 수치 변경의 최우선 후보**는 카타쿠리의 Defense/Technique/Combat IQ 중복과 샹크스의 신피 관련 다중 Raw. 하지만 **검증되지 않은 정확한 ±2점**을 만들거나 샹크스를 링링 위로 올리는 식의 사후 서열 보정은 하지 않는다.
