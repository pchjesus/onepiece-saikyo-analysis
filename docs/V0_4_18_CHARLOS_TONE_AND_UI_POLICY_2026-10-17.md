# v0.4.18 — 차를로스 성 말투·개그 UX 정리 및 일반 캐릭터 UI 정책 (2026-10-17)

## 승인 요구사항과 범위
- 차를로스 성 페이지에서 “실제로는 풍자”, “프로젝트 창작”, “특별 별칭”, “정규 전투력 모델과 무관”, “밈 7축 평균”, “공식 대사 아님” 등 **개그를 직접 설명하는 사용자 노출 문구 제거**.
- '천룡인식 평가'는 진심으로 자신을 칭찬하듯 끝까지 **~다이** 문체 사용. 사실을 부정하거나 새 정사인 척 데이터에 편입하지 않음.
- 대표 대사 **“5억 베리이~~~~!!! 5억에 사겠다이~~!!!”** · 출처 표시 **원피스 51권**으로 교체. 본 문장은 사용자 지정 편집 문구로서 정발판 정확한 따옴표 인용을 검증했다고 주장하지 않음.
- '호를로스 성'은 **“부산 고신대 의대의 또 다른 차를로스 성”**으로 사용자 제공 프로젝트 인물설정. 실존 특정 개인에 관한 사실 또는 원작 캐릭터의 실제 이명으로 판정하지 않음.
- '진실' 팝업의 반전 서사 뒤에 풍자의 뜻을 해설하는 문구 제거. 접근성·암전·모션·닫기 기능 보존.
- **디자인 정책:** 차를로스 성은 이미 승인된 1인 세계귀족 특별 전형. 앞으로 그 외 일반 신규 캐릭터는 기존 공통 `CharacterPage` 사용. 별도 특수 UI는 명시적으로 승인받을 때만 도입.
- 기타 코드 변경 없이 82명 로스터, 85개 정규 Evaluation, 595개 정규 축, 18개 매치업, 특별 7축 점수 및 Overall 611/7, Balanced1.2/Haki .5, 고정 v0.3.3 기준선 모두 유지.

## 기술적 경계
- 사실·풍자 구분은 `src/data/special/charlosSpecial.ts`의 `fact`, `satire`, `sourceUrl` 및 문서에서 유지하되, 유머 페이지에 편집자 설명을 표시하지 않음.
- 정상 인물 평가 상태·순위 모델 재구성 없음. 인물 기본 UI의 별도 분기 외 일반 CharacterPage 변경 없음.
- 앱 표시 버전만 `0.4.18`로 올리고, 평가·코어 데이터셋은 이전 `core-v0.4.17 / evaluation-set-v0.4.17` 유지. 이전 패치 기록은 불변.
- 공개 이미지 권리 상태는 사용자 제공·권한 미검증 그대로. **저작권 위험은 대외 메타 기록에 남기되 캐릭터 유머 화면에서 반복 설명하지 않음.**
- 일반 UI 기본 원칙은 `AGENTS.md`, `docs/PROJECT_GUIDE.md`에 기재.

## 검증 계획
- 차를로스 페이지에서 삭제 요구 문구가 재등장하지 않는지, '원피스 51권'과 갱신 대사가 정확히 표시되는지 UI 테스트.
- '인정력'의 100점, 점수 일곱 개, Overall 87.3, 전체 순위 82, 정규 81/85/595/18, 이미지 경로 및 진실 팝업 암전·Escape 확인.
- 108개 파일의 전역 테스트와 TypeScript/Vite 프로덕션 빌드, PR 병합 후 실제 GitHub Pages Actions 성공 여부 확인. PC·모바일 실기기 시각 검수는 별도.

## 이미지 품질
- 기존 `charlos.webp`와 `charlos-truth.webp`는 사용자 제공 1536픽셀 원본을 300픽셀·강한 손실 압축으로 줄여 화면 확대에서 질감이 손실됨.
- 사용자가 가능한 한 원본의 화질과 비율을 보존하도록 요청. 자산 재압축·원본 재등록 여부와 실제 반영 상태는 최종 배포 확인 결과에 별도 기록.

## 참고 기록
- 원작 사실은 ONE PIECE.com 보조자료와 사용자 업로드 이미지를 구분해 보존.
- 차를로스 성 구원자 서사·호를로스 성 설정은 실제 원피스 공식 설정이 아닌 프로젝트 내부 이야기.

## 후속 UX 핫픽스 — 원본 해상도 복구 및 캐주얼 타이포그래피 (2026-10-17)

- 문제: 차를로스 기본/진실 이미지가 **원본 1536px**에서 **300px**로 지나치게 축소됨. 타 캐릭터에 비해 확연히 흐려짐.
- 해결: 사용자 제공 원본의 픽셀 크기 그대로 WebP 압축한 검증 파일 사용. 기본 **1536×1230 / 89,522 bytes / SHA-256 bad5d4e4e3fd74997a272c0205bfcc220d8ccdb5a77f1fb2a16bc5efb511e065**, 진실 **1536×1536 / 107,410 bytes / SHA-256 04695f2434333ff46b8a40d7a3cbde21b2c8e6f766cacba57d74da7c086109cf**. Git blob SHA가 소스 바이트에서 독립 계산한 Git 해시와 일치함.
- GitHub 현재 경로를 `public/images/characters/charlos-v0418.webp` / `public/images/characters/charlos-truth-v0418.webp`로 변경하고 구 300px URL 제거. 브라우저 캐시가 이전 작은 이미지를 계속 띄우는 문제 방지.
- 차를로스 전용 CSS에서만 제목·원피스 51권 인용·진실 3줄 등 `Georgia/Noto Serif KR` 명조를 **시스템 산세리프·800 중심**으로 조정. 톤은 좀 더 가볍고 두툼하게, 금색/아이보리 색상과 기존 레이아웃·암전 애니메이션은 유지.
- 정규 CharacterPage 및 공유 스타일, 81명의 정규 평가와 85 Evaluation/595개 정규 축, 18 Matchup, 특별 7축 점수/Overall, v0.3.3 고정 JSON은 불변.
- 새 테스트는 full-resolution bytes, WebP RIFF/VP8 크기, 파일 해시, 참조 경로를 검사. CI와 Pages 검증 결과는 별도로 확인한다.


## 후속 UI 수정 — 모바일 행 배치·호를로스 성 배지·기존 ‘진실’ 복구 (2026-10-17)

**사용자 직접 검수:** Android 모바일 스크린샷. 소개 문구가 부자연스럽게 끊기고, 지배력·기동력 등 한 줄 평가가 2줄로 갈라짐. 호를로스 성의 칭호가 일반 설명처럼 표시되며, 기동력·인정력 설명이 외부 해설자 말투임. 이전 지시였던 "세 줄만"은 **기존 서사를 지우라는 뜻이 아니라 3줄을 한 덩어리로 추가**하라는 뜻으로 바로잡음.

- **호칭:** 별표(`*`) 접두가 들어간 테두리형 `charlos-alias-badge`. 부산 고신대 의대의 또 다른 차를로스 성 설정 유지.
- **상단 문구:** `세계귀족의 위상은 평범한 전투력으로 설명할 수 없다이.`와 `내 평가는 내가 정하는 거다이.`를 별도 span 블록으로 구분하고 모바일에 여유 있는 행간 적용.
- **7축 리스트:** 모바일(최대 700px)에서는 기존 4열 배치가 설명을 좁게 만드는 문제를 해결하고, 번호·이름·점수·확장기호를 첫 줄, 짧은 대사를 **전체 너비 둘째 줄**, 바 그래프를 셋째 줄에 둠. 355px 이상에서 가능한 한 한 줄 유지, 작은 화면/확대에서는 자동 줄바꿈 허용. 내용 잘림 없이 가독성 유지. 일반 캐릭터 CSS 변경 없음.
- **화법:** 7축 `fact` 전부 차를로스의 1인칭 `~다이` 대사로 통일. 공식 사건/URL/평가 수치/전투 모델은 불변.
- **진실 원상복구:** 직전 팝업 축소 이전의 병합 커밋 `38502baacea2b05eb6585f3162fc000083ffb2a9`에서 `charlosTruthLines`의 최종 승인 문구 5문장과 팝업 헤더·인류의 구원자 제목·기존 이미지 캡션·`일어나 죽지 말고, 엎드려 사는 거다이.`·`악마다이…!!`·마지막 문장·닫기 버튼을 정확히 회수. 기존 저작권/풍자 해설을 화면에 되살리지는 않음.
- **3줄 추가:** `charlosTruthMonologue` 내용은 한 글자도 바꾸지 않고 **기존 서사 5문장과 마지막 속삭임 사이** 한 블록으로 삽입. 원본 글은 삭제하지 않음. `charlos-truth-v0418.webp` 고화질 파일, 암전·접근성·Escape·줄임모션 유지.
- **불변:** 버전은 v0.4.18 후속 UI 패치, 기존 82명 로스터/81명 정규 평가·85 Evaluation/595축/18 매치업·배포 원본 이미지 2개·특별 7축 점수 및 Overall 87.3, Balanced 1.2/Haki 0.5·v0.3.3 고정 JSON 유지.
- **검증:** 현재/복구 문구 비교, 세 줄 단일 삽입/정확성, 모바일 CSS 세 행 분리와 작은 화면 폴백, 기존 결과 회귀 테스트. GitHub CI/실제 Pages 결과는 완료 후 확인하며 실제 모바일 브라우저 시각 검증과 혼동하지 않음.

이 내용은 위에 기록된 "팝업 3줄 고정·기존 서사 삭제"라는 이전 결정 설명을 **최신 사용자 수정 지시로 대체**한다.
