# v0.4.18 — 차를로스 성 말투·개그 UX 정리 및 일반 캐릭터 UI 정책 (2026-10-17)

## 승인 요구사항과 범위
- 차를로스 성 페이지에서 “실제로는 풍자”, “프로젝트 창작”, “특별 별칭”, “정규 전투력 모델과 무관”, “밈 7축 평균”, “공식 대사 아님” 등 **개그를 직접 설명하는 사용자 노출 문구 제거**.
- '천룡인식 평가'는 진심으로 자신을 칭찬하듯 끝까지 **~다이** 문체 사용. 사실을 부정하거나 새 정사인 척 데이터에 편입하지 않음.
- 대표 대사 **“5억 베리이~~~~!!! 5억에 사겠다이~~!!!”** · 출처 표시 **원피스 51권**으로 교체. 본 문장은 사용자 지정 편집 문구로서 정발판 정확한 따옴표 인용을 검증했다고 주장하지 않음.
- '호를로스 성'은 **“부산 고신대 의대의 또 다른 차를로스 성”**으로 사용자 제공 프로젝트 인물설정. 실존 특정 개인에 관한 사실 또는 원작 캐릭터의 실제 이명으로 판정하지 않음.
- '진실' 팝업의 반전 서사 뒤에 풍자의 뜻을 해설하는 문구 제거. 접근성·암전·모션·닫기 기능 보존.
- **디자인 정책:** 차를로스 성은 이미 승인된 1인 세계귀족 특별 전형. 앞으로 그 외 일반 신규 캐릭터는 기존 공통 `CharacterPage` 사용. 별도 특수 UI는 명시적으로 승인받을 때만 도입.
- 기타 코드 변경 없이 82명 로스터, 85개 정규 Evaluation, 595개 정규 축, 18개 매치업, 특별 7축 점수 및 Overall 611/7, Balanced1.2/Haki .5, 고정 v0.3.3 기준선 모두 유지.

## 기술적 경계
- 사실·풍자 구분은 `src/data/special/charlosSpecial.ts`의 `fact`, `satire`, `sourceUrl` 및 문서에서 유지하되, 유머 페이지에 편집자 설명을 표시하지 않음.
- 정상 인물 평가 상태·순위 모델 재구성 없음. 인물 기본 UI의 별도 분기 외 일반 CharacterPage 변경 없음.
- 앱 표시 버전만 `0.4.18`로 올리고, 평가·코어 데이터셋은 이전 `core-v0.4.17 / evaluation-set-v0.4.17` 유지. 이전 패치 기록은 불변.
- 공개 이미지 권리 상태는 사용자 제공·권한 미검증 그대로. **저작권 위험은 대외 메타 기록에 남기되 캐릭터 유머 화면에서 반복 설명하지 않음.**
- 일반 UI 기본 원칙은 `AGENTS.md`, `docs/PROJECT_GUIDE.md`에 기재.

## 검증 계획
- 차를로스 페이지에서 삭제 요구 문구가 재등장하지 않는지, '원피스 51권'과 갱신 대사가 정확히 표시되는지 UI 테스트.
- '인정력'의 100점, 점수 일곱 개, Overall 87.3, 전체 순위 82, 정규 81/85/595/18, 이미지 경로 및 진실 팝업 암전·Escape 확인.
- 108개 파일의 전역 테스트와 TypeScript/Vite 프로덕션 빌드, PR 병합 후 실제 GitHub Pages Actions 성공 여부 확인. PC·모바일 실기기 시각 검수는 별도.

## 이미지 품질
- 기존 `charlos.webp`와 `charlos-truth.webp`는 사용자 제공 1536픽셀 원본을 300픽셀·강한 손실 압축으로 줄여 화면 확대에서 질감이 손실됨.
- 사용자가 가능한 한 원본의 화질과 비율을 보존하도록 요청. 자산 재압축·원본 재등록 여부와 실제 반영 상태는 최종 배포 확인 결과에 별도 기록.
