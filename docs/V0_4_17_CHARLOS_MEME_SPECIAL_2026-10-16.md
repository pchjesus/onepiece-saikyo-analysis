# v0.4.17 — 차를로스 성 · 천룡인 특별 밈 평가 (2026-10-16)

## 사용자 승인 범위
- 총 들고 뛰는 차를로스 성 그림 = 기본 초상, 눈물 흘리는 흑백 그림 = '진실' 히든 팝업. 두 파일 모두 사용자가 직접 제공. 웹 전달용 300px WebP 변환본을 저장했으며 업로드된 blob SHA와 로컬 파일 SHA 동일. **원저작권·재배포 허가는 검증되지 않음.**
- 차를로스 성을 세계정부 하위 `천룡인` 그룹에 추가하고, **오버롤 순위에는 포함**. 총질력/맷집력/배포력/지배력/기동력/인정력/어그로력 전용 7축을 별도 표시.
- 모든 한 줄 밈 평가와 서술은 천룡인식 '~다이' 말투. 창작 대사는 원작 공식 대사인 것처럼 표시하지 않음.
- '진실' 클릭 시 짧은 암전 후 흑백 삽화·“일어나 죽지 말고, 엎드려 사는 거다이”·가짜 인류 구원자 서사 표시. 등장·전환 애니메이션, 키보드 Escape, 닫기 포커스 복귀, 모션 감소 모드 적용.

## 데이터·계산 격리
- 특별 7축: 총질력 **23** / 맷집력 **97** / 배포력 **100** / 지배력 **99** / 기동력 **92** / 인정력 **100** / 어그로력 **100**.
- `(23+97+100+99+92+100+100)/7 = 611/7 = 87.285714...`. 표시 **87.3/100**. 개인 전투력을 뜻하지 않는 **밈 평균**이며, 기존 Balanced 1.2 계산 엔진과 무관.
- `src/data/special/charlosSpecial.ts`에 팩트/풍자/출처/점수를 분리한 최소 정적 구조. 일반 `Evaluation`이나 `Battle/Evidence`를 위조하거나 재활용하지 않음.
- 그룹은 기존 세계정부 하위 새 Group `celestial-dragons`. 기존 Group 목록 원본, 기존 81인의 Character/Evaluation 원본, v0.3.3 독립 JSON, 18 Matchup은 미수정.
- 현재 화면 로스터 **82명**, 정상 정규 전투력 평가 **81명**, 정규 Evaluation **85**, 정규 7축 **595**, 일반 Matchup **18**. 오버롤 82위까지 정렬되며 7개 일반 개별 스탯의 순위는 기존 81명 그대로. 기존 81명의 **점수는 불변**, rank 번호는 삽입에 따라 일부 이동.
- 이전 `v050CurrentDataset` 81명/85 Evaluation/595축 전수 감사 보고는 정규 평가 코호트로 유지. **새 풍자 캐릭터는 그 감사 모델 밖**. 현재 실사용 로스터 총 인원과 전수 감사 대상 수는 의도적으로 1명 차이.
- 사용자 제공 기본 이미지 `public/images/characters/charlos.webp`, 히든 이미지 `public/images/characters/charlos-truth.webp`. 서로 다른 역할로 경로 고정.

## 원작 사실과 밈의 경계
1. **공식 출처(보조)**: ONE PIECE.com 샤본디 TV396 공식 줄거리: 케이미 경매에서 5억 베리 제시. 실제 지출 완료는 미확인.
2. ONE PIECE.com 세계회의 TV886 줄거리: 시라호시를 둘러싼 개입, 루치와 묘스가르드. 공식 세계회의 줄거리도 폭력 사건을 요약.
3. ONE PIECE.com TV1118: 시라호시를 붙잡기 위해 쿠마를 동원, 사이·레오 공격.
4. ONE PIECE.com 인물 소개: 차를로스는 마리조아의 세계귀족이자 로즈워드 성의 아들로 **잔혹한 행동을 태연히 반복**.
5. **프로젝트 창작 풍자**: 모든 0~100 밈 점수, '인간을 누구보다 사랑한다', '악역을 연기하는 구원자', '~다이' 형식의 패러디 한 줄, 가짜 기밀 기록, 팝업 내용. 실제 원작 반전이나 확인된 팬덤 정설이 아님.
6. **권리·출처 제한**: 사용자 제공 그림이라는 사실은 배포 권한 검증과 다름. 원본 만화 컷/공식 한국어판 문구 직접 대조는 하지 않음. 이미지 크롭/압축은 소스의 연출과 내용 자체를 변경하지 않음.

## 위험·회귀
- 기존 모든 점수/계산 모델/매치업/Evidence는 그대로 유지. 풍자 점수가 오버롤 정규 평가와 혼합 정렬되므로 **특별 밈 평가** 라벨을 일반 순위 행/상세 모두에 명확히 표시함.
- 특별 프로필은 기본 상세 페이지의 계산과 상태 기능을 사용하지 않고 별도 `CharlosSpecialPage`로 라우팅하며, 일반 미평가 페이지로 잘못 분기하지 않음.
- 기존 Stats/Matchup/조직도/초상 확대/모바일·키보드 동작을 변경하지 않도록 영향 최소화.
- `src/data/special/charlosSpecial.test.tsx`: 전용 일곱 축, 87.3, 82인 로스터, Overall 82/개별 81, 평가/대진 격리, 세계정부 조직도, 초상 등록, 히든 열기/닫기/Escape.
- CI/빌드 및 배포 결과는 검증 후 TEST_REPORT에서 보고. jsdom 자동 테스트만으로 실기기 PC·모바일 시각 검증을 완료했다고 간주하지 않음.
