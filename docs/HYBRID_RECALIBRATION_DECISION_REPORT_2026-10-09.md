## 2. 중요한 발견과 오류 구분

### A. 출처 연결의 문제 (우선)

**14개의 직접 미연결 축**
- 샹크스: **Stamina 88**.
- 사카즈키: **Speed 86, Technique 91, Combat IQ 91, Versatility 91**.
- 잇쇼/후지토라: **Defense 88, Stamina 87, Speed 85**.
- 아라마키/료쿠규: **Attack 90, Stamina 89, Speed 84, Technique 87, Versatility 92**.
- 샬롯 스무디: **Speed 74**.

이 값들이 **틀렸거나 부족하다**고 증명된 것이 아니다. 다만 재현 가능한 개별 수치의 근거와 신뢰도를 주장하기 어렵다. 원작/공식 자료를 추가 확보하거나 `E2/E3 provisional` 근거 부족을 분명히 하고, 필요 시 숫자 평가를 보류해야 한다. 미연결이면 +N이나 -N으로 자동 조절하는 건 금지한다.

### B. Base vs Raw의 의미 충돌

하이브리드 확정 기준은 실제 전투에서 분리 불가능한 통상 패기 적용을 **Base**에 두고, 유독 탁월한 응용이 독립적으로 준 추가 효과에 한하여 **Raw**를 검토한다. 반면 레거시 평가 문구는 `Base에서는 Haki 제외, Raw로 분리`를 전제로 한 사례들이 많다.

**동일 레거시 숫자를 그대로 둔 채 새 기준이 완전히 적용됐다고 선언하면 안 된다.** 재산정은 단순 Haki 가중치 변경이 아니라 Base의 **정의/앵커를 다시 고정**하는 작업이다.

특히:
- **로저/전성기 가프/전성기 뉴게이트/록스**는 하나 또는 소수의 최상급 패기 공방에서 Attack + Defense + Technique에 각각 Raw 8씩 배분한다. 독립된 효과가 세 가지 확인됐는지와 다인전 영향을 분리해야 한다.
- **카타쿠리**는 Future Sight를 Defense +6 / Technique +6 / Combat IQ +4에 분리한다. 직접적인 특출난 견문색은 명확하지만 회피, 회피 기법의 숙련, 예지 기반 판단을 *동일한 회피 성과 세 번*으로 계산했는지 다시 검토해야 한다.
- **샹크스**의 키드전은 Attack 패왕색 +6, Technique 패왕색 +4/견문색 +4, Combat IQ 견문색 +4의 Raw 후보와 Speed·Base 성과에 모두 등장한다. 서로 다른 사실(미래 예지, 위험 우선순위, 고속 접근, 결정타)을 인정하되 **하나의 결정타에 보너스 네 번을 더하지 않는다**.
- **조로**는 King전 Attack에 무장색 +4 및 패왕색 +6이 함께 사용되며, 각 양분의 차별적 한계효과가 분명해야 한다.
- **쿠잔**은 Garp 상대 Ice Glove를 Attack +4와 Technique +4에 반영한다. **사카즈키 Raw +2**와의 차이가 전체 패기 능력 우위가 아니라 장면별 명시적 기여의 차이인지 감사해야 한다.
- **레일리 현재**는 훈련·원리 시연이 Attack/Technique Raw를 일부 지지한다. 교육/시연이라는 사실만으로 현재 동급 강자 실전에서 분리 가능한 공격력 증가를 추론하지 않는다.
- **미호크**의 Raw 0은 패기 부족의 근거가 아니다. 흑도 「夜」와 패기 지도는 강한 무장색 숙련을 **추론**하게 하지만, 영구 흑도의 직접 제작 경위와 패기 기여는 확정되어 있지 않다. 무장색 Raw +N 자동 가산 없음.
- **로/핸콕/티치/전성기 레일리/도플라밍고**의 Raw 0 역시 Haki 무능의 징표가 아니다.

## 3. 실제로 검증한 재산정 시나리오

### 실험 A — 기존 Raw를 통상 Base로 순수 이관 (중립 Shadow)

각 항목별:

`NewBase = min(100, OldBase + 0.5 × OldTypedRaw)`  
`NewTypedRaw = 0`  
`NewFinal = min(100, NewBase + 0.5 × NewTypedRaw)`

→ **39개 전체 Evaluation, 273개 Stat에서 기존 Final, Overall 및 순위가 정확히 유지되어야 한다.** 신규 회귀 테스트가 이 성질을 실행한다.

**주의:** 이건 기존 총점의 분해 방식을 바꾸는 *수학적* 실험일 뿐이고, 중복 부여를 제거하거나 새로운 특별 패기의 가치를 입증하지 않는다. `newBase`를 실제 데이터에 덮어쓰지 않았다. `NewTypedRaw=0`이 영구 정책이라는 뜻도 아니다.

### 실험 B — 진정한 하이브리드 재산정 (현재 미확정)

`NewFinal = min(100, independently_recalibrated_Base + 0.5 × approved_ExceptionalRaw)`.

핵심 입력인 `independently_recalibrated_Base`와 `approved_ExceptionalRaw`는 **전체 273축에서 아직 확정되지 않았다.** 따라서 실험 B에 대한 정량 Overall 순위 변화를 **정당한 추정값처럼 생성하지 않는다**.

대신 `docs/HYBRID_RECALIBRATION_273_STAT_AUDIT_2026-10-09.md`의 각 축에 근거 링크·역할·현재 수치·추가 검토 플래그를 남겼다. 다음 심사자가 추가할 것은 각 축의 **재산정 후보·Base에서 제외된 실측 기여·반대 근거·시점 조건·동급 앵커**다.

## 4. 39-Evaluation 재평가 우선순위

- **P0: 기존 숫자와 근거의 불일치 가능성이 높은 축:** 14개 미연결 Stat이 포함된 평가(샹크스, 사카즈키, 후지토라, 료쿠규, 스무디); 복수 Raw 활용/직접 앵커 충돌(로저, 흰수염 전성기, 가프 전성기, 록스, 카이도, 링링, 쿠잔, 미호크, 조로, 카타쿠리); 소수 장면에서 고위 점수(전성기 레일리, 현재 가반).

### 결론

**현재 모델에 실제로 존재하는 문제는 90점대 서열 하나가 아니라, 전체 39개 평가의 근거 밀도, 예외적 Haki 효과의 미확정, Base/Raw 해석 차이다.** 중립적 수치 보존과 구조적 감사는 이번에 수행했지만, 전체 최종 점수의 원작 단위 **재보정 완료**라고 발표할 단계는 아니다. 검증 가능한 근거가 모이는 순서대로만 값의 위·아래 조정을 제안한다.
