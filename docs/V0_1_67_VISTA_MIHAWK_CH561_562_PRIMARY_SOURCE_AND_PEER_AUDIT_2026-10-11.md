### 비스타 Technique 외 6축으로의 영향 — 관찰과 독립효과를 구분

- **Attack:** 미호크에게 검격 교환을 성립시켰으나 유효 손상·방어 파괴가 확인되지 않음.
- **Defense:** 공방에 대응한 정성적 근거는 있으나 어떤 공격을 막고 피했는지 컷별 불분명. 정면 내구도 자동 상승 금지.
- **Speed:** 요격과 교환은 대응 능력을 시사. 위치·선행 거리·순간 검속 정보 없이 순수 이동속도 순위로 전환 금지.
- **Stamina:** 두 화에 걸친 서술은 연속 격전 시간/피로 수치가 아님.
- **Combat IQ:** **마르코 지시/비스타 수행** 가능성에 특히 유의. 독자적 전략 설계와 역할 수행을 구별하고, 현재 77점 감점·상향 없이 E3 불확실성 유지.
- **Versatility:** 한 가지 이도류 기반 공격/방어/요격의 역할 전환은 인정하지만 원거리 공격/특수능력의 실체를 추가 추정하지 않음.

## 3. Technique 비교군 — 실제 저장된 Base/Raw/Final 및 직접 비교성

동일한 7축 모델은 Technique를 단순 검술의 '날카로움'이 아니라 **각자의 전투 수단 운용 완성도**로 정의한다. 따라서 검술 대 검술 앵커와 이종 능력의 기법 숙련을 엄밀히 구분한다.

| 캐릭터 | 기존 Base / Haki Raw / Final | 준비도 | 비교 적합성 | 무엇이 비교 가능한가? |
|---|---|---|---|---|
| **미호크** | **99 / 0 / 99** | E1 | **직접 검술 비교** | 세계 최강 검사, 흑도 「夜」·원거리 정밀 검격, 비스타와의 실전 교환. 99점은 프로젝트 자체의 상단 평가 |
| **비스타** | **86 / 2 / 87** | E1 | **직접 검술 비교** | 공식 '호각으로 겨룰 정도의 이도류', 정상결전 근접 교환. Raw2는 Ch.574의 별개 합동 사건에서 옴 |
| **조로** | **85 / 4 / 87** | E1 | **상당히 유사, 시점·패기 다름** | 삼도류/엔마 제어·킹전 패기 결합의 다른 사건. Final87 동점이라도 Base85/Raw4 vs 비스타 Base86/Raw2 |
| **킹** | **80 / 0 / 80** | E2 | **일부 검술만 비교 가능** | 검술과 화염·루나리아·고대종 수단 혼합. 원래 무장 Raw 제거는 v0.1.62 승인 중복 정리 |
| **마르코** | **84 / 0 / 84** | E2 | **광의 Technique 비교만** | 불사조의 변형·회복·전선 지원 숙련. 순수 검술 척도 아니므로 84 vs 비스타87을 검술 서열로 읽지 않음 |

**재평가 핵심:** 미호크 99와 비스타 87의 **12점 Final 차이**가 곧 원작이 보여준 실제 검술 차이 12점이라는 주장은 성립하지 않는다. 현행 두 인물의 Base 구성이 각각 **99/86**이고, 비스타는 다른 Ch.574 무장색 Raw2(+1 Final)를 포함한다. 비교군의 패기 Raw 기준과 Technique가 포괄하는 기술 형태를 함께 보아야 한다.

공식 비스타의 호각 표현은 비스타 Technique를 **지금보다 높일 가능성을 검증할 강한 이유**지만, 실제 Ch.561·562의 검술 공방·상대 의도·기술 난이도를 직접 확인하지 못했기 때문에 **+3 후보 또는 90점의 정당성은 아직 입증되지 않는다**. ‘미호크가 본래 강자이니 비스타는 87 이상일 수 없다’는 역방향의 기계적 고정 판단도 하지 않는다.

## 4. 기존 Evidence 및 해석의 충돌 가능성 검토

1. **`evidence-vista-mihawk-561-562` — primary Technique·secondary Attack/Defense/Speed/Versatility:** 역할 연결은 현재 기능별로 구분돼 구조적 모순 없음. 다만 해당 기여들이 **독립적인 관찰 효과로 완전히 분해되었다는 근거 부족**. 새 수치 승인 전 필수.

3. **비스타 Combat IQ77 설명:** ‘적절한 강자 요격과 교전 중단 판단’은 수행 결과가 맞더라도 **마르코가 명령한 경우 목표 수립의 단독 업적이 아님**. 2차 요약을 보고 원작으로 확정하지 않고 리뷰 메타데이터에 위험을 남김. 실제 정정/평가 재보정은 컷 확인 이후.
4. **비스타 Technique Raw2:** Ch.574의 일반 무장색 적용만으로 ‘독립적으로 특출난’ +1 Final을 완전히 재인증하기 어렵다는 이전 지적 유지. 동시에 이 Raw를 제거하거나 비스타의 잠재 점수를 가상 감점하지 않음.
5. **현재 E1의 의미:** 현행 원작 기록과 공식 강한 서술에 충분한 연결성이 있다는 메타데이터다. **필요한 세부 기술 컷·패기 응용·정량 차이 모두에 원작 직접 검증 완료를 의미하지 않는다.**

5. 원작 직접 자료가 계속 미확보라면 **E1의 공식 검술 근거는 인정하되 상세 +N 판단은 유지 보류**. 신규 캐릭터 집단·모델 변경은 이번 범위에 넣지 않는다.
