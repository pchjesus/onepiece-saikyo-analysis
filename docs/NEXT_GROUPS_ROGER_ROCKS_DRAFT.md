## 3. Haki Audit 규칙

1. Capability: 해당 Haki 타입 보유 여부
2. Demonstrated Performance / Stat Application: 실제 특정 Stat 성과에 해당 타입이 사용됐는가
3. Matchup Interaction: 특정 상대 능력·방어·재생과 어떻게 상호작용했는가

Haki 보유만으로 Raw Contribution을 만들지 않는다.
장면에서 단순히 Haki라고만 묘사되고 타입이 특정되지 않으면 Armament / Observation / Supreme King으로 임의 배분하지 않는다.
