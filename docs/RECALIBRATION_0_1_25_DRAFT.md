## 4. 계산식과 버전 무결성

현재 모델 **Balanced 1.2 고정**:
```text
Raw Haki(stat) = 해당 스탯에 검증된 패기 가산점 합 (0 ~ 10)
Effective Haki = Raw Haki × 0.5
Final Stat = min(100, Base Stat + Effective Haki)
Overall = 7개 Final Stat 합 ÷ 7
```

Examples:
- 샹크스 Attack: `94 + 6×0.5 = 97`
- 샹크스 Technique: `93 + (4+4)×0.5 = 97`
- 샹크스 Combat IQ: `92 + 4×0.5 = 94`
- 가프 Attack: `96 + 6×0.5 = 99` (분해 전후 Final 99 동일)
- 쿠잔 Attack: `91 + 4×0.5 = 93`
- 보르살리노 Defense: `88 + 2×0.5 = 89`
- 상디 Defense: `85 + 0 = 85` (방어 패기 중복 근거 정리)

`src/domain/evaluation/score.ts`, `src/domain/calculation/calculateCombatPower.ts`, `src/data/sample/calculationModels.ts`는 **변경하지 않는다**. 계산 모델 1.2와 Dataset `evaluation-0.1.25-draft`를 구별한다. 평가/근거 갱신 대상 10명 이외의 원래 데이터 버전은 유지한다. 안정 버전 번호 상향은 추후 PR 승인·병합 시 검토한다.

## 6. 남은 평가 불확실성

1. 가프는 전성기 비교 모델인데 구체 Evidence 2건 모두 노년의 하치노수다. 로저와의 대등한 위상을 정량화한 Base 추론이 여전히 크므로 Prime 고점을 확정치처럼 소개하지 않는다.
2. 샹크스의 미래예지가 Technique/Combat IQ의 서로 다른 의미를 입증하더라도 단일 장면 활용에 의존하는 한계가 있다. Raw 과다 반영 여부는 추가 검토 가능하다.
3. 사카즈키·쿠잔의 결투 승패는 확인되지만 개별 기술 교환이 생략되었다. 승패를 Overall과 일치시키기 위한 임의 가산은 하지 않는다.
4. 퀸·잭·스무디·아라마키·반 오거·피사로 등에서 `Haki Raw 0`은 패기 능력이 없거나 약하다는 판정이 아니다. 원작 실전 Application의 부족을 의미한다.
5. 시류 무장색은 1087화 검격에 기반해 confirmed/Raw A2로 처리하지만, 상대가 보호 개입 중이었다는 점은 Attack Base 상향으로 환산하지 않는다.
6. 24인 모두 구조·Evidence 링크·계산 자동 검증을 했더라도, **각자의 7개 스탯 점수가 외부 독립 평가로 모두 확정·검증됐다는 뜻은 아니다.** E2 잠정 추론과 과거 근거 한계를 계속 표시한다.
