# v0.1.73 — 전체 65명, 455개 스탯 간극 전수 감사

**기준 GitHub `main@eaa8a3bacd2dfab95fd1e053b9cbcaea182a307c` (v0.1.72)** · 2026-10-11

이 문서는 기준점 검증 후 **65명 대표 Evaluation의 7축 Final 455개를 전부 읽고** 점수 분포·상대 비교의 이상 사례를 찾은 **1차 정량 전수 감사 + 38개 선택적 정성 검토**다. 실제로 455개 모두의 원작 장면을 각각 독립 페이지 단위로 재검증했다는 뜻은 아니다.

**중요: 기존 어떤 점수도 바꾸지 않았다.** PROJECT_SPEC, 68개 Evaluation(과거 상태 3건 포함), 원작 근거 데이터, 모델 Balanced1.2, HakiWeight0.5 및 직접 매치업15개는 모두 불변. 새로운 읽기전용 계산·회귀 테스트·이 문서만 추가. AI가 가설만으로 스탯을 고치거나 오버롤을 맞추기 위해 다른 축을 보상 조정하지 않는다.

- 90 이상: 14명 / 80 이상 90 미만: 10명 / 75 이상 80 미만: 31명 / 70 이상 75 미만: 10명. 이는 현재 상위 인물 위주 표본의 **현재 결과**이지 원작 공식 티어 경계가 아니다.
- 고정된 Overall 기준은 로저·전성기 흰수염·카이도·키자루·카타쿠리 **5명**뿐. 가장 낮은 고정 기준 카타쿠리84.000 아래에 **43명**이 몰려 있어 저·중위권 눈금은 아직 비어 있다.
- **전체 65명 단순 평균**은 순위의 강약을 정하는 비정상적인 보정 도구가 아니다. 하위권 분포를 보기 위해 E3를 자동 하향하거나 오버롤 점수끼리 일정 거리로 벌리는 것도 금지한다.

### C. 시점 혼합: 발견된 구조적인 눈금 위험

1. **레일리 전성기 vs 가반 현재** — 기본 랭킹은 전성기 레일리92.857과 **노년 현재 가반92.143**을 함께 표시한다. 이것을 둘의 동시기 0.714점 차이로 해석하는 것은 명백한 시점 비교 오류다.
2. 별도의 **노년 레일리90.286**(비대표 Evaluation)와 노년 가반92.143 사이에는 오히려 가반 +1.857의 차이가 있다. 최근 가반 전투와 레일리 자기평가를 같은 범위의 근거로 비교할 수 있는지 먼저 따져야 하며 **현재 수치의 옳고 그름은 확정하지 않는다**.
3. 전성기 거프97.429(E3 4개), 전성기 레일리92.857(E2 7개), 록스97.286(특정 상태), 현재 티치90.571, 전성기 흰수염97.571과 마린포드 흰수염92.857(비대표 상태)도 **원래 서로 다른 시점/상태**다. 기본순위 단일 표기만으로 세부 매치업 성과 비교 불가.
4. 본 프로젝트는 캐릭터의 상태별 Evaluation 저장을 지원하므로 **지금의 사실은 데이터 누락보다 랭킹 해석 시 상태 라벨/조건을 명확히 해야 한다는 요구**에 가깝다. 이번 패치에서 목록 UX/정렬 방식을 임의 변경하지 않았다.

- **두 번째:** 스무디·몰리·카라스·로쿠규·고대종 하위 및 아카자야의 E3 집중 축. 원작/공식 자료 부족을 높은/낮은 절대 전투력이라고 확정하지 말 것.
- **세 번째:** 대장급·상위 사최간·최상위 전설의 고정축 회귀와 Haki Raw 이벤트 독립효과. 고정된 5개 Overall을 원칙적으로 보존하되 정당한 변경 사유가 나오면 고정 기준을 재승인하고 버전 기록 남길 것.
- **저·중위권 눈금:** 카타쿠리84 아래 43명에 대해 기존 직접 결투가 풍부한 **징베79.286·크래커77.857·울티75.143 등의 '추가 고정 후보'**를 제안할 수 있다. **아직 실제 고정하지 않는다.**
- 새로운 매치업을 임의 생성하거나 원작 장면 없이 +1~-5의 보정값을 산정하지 말 것. 간극만으로 대체 점수를 확정하는 것은 기준점 강제 끼워넣기 문제를 재현한다.
