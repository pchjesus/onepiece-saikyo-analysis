# v0.6.0 매치업 근거·전투 조건 추적성 개선 — 통합 개발 기록

> 개발 기준 `main c71368a9bb8b5851134b9a79172a47d6d1ae0e9c` / 기존 앱 0.4.34 / `0.5.0-review.1` 전체 평가 감사 종결 상태. **이번 PR은 v0.6 개발 범위의 첫 통합 사용자 기능 개선이며, 평가 모델 및 데이터 변경을 승인하지 않는다.** `PROJECT_SPEC.md` 불변.

## 목적과 현재 구조

기존 Matchup Arena는 좌우 선택·교체/랜덤·추천 대진·개인 스탯/전투 방식·요인 요약/조건/불확실성은 보여주지만, 각 요인의 Evidence ID 및 그 Evidence가 발생한 **실제 전투 조건**을 UI에서 직접 추적하기 어렵다. 요인의 `confirmed`는 **승리나 정량 승률 확정**이 아니다.

현행 저장소의 등록 대진은 **18개 / factor 62개**다.

| 자료 | 대진 | Factor | 성격 |
|---|---:|---:|---|
| `sample/matchups.ts` | 15 | 46 | 기존 Evidence-aware 정성 대진 |
| `sample/luffyTeachStateMatchups.ts` | 2 | 10 | 루피 상태별 가상 조건부 대진 |
| `sample/enelLuffyHistoricalMatchup.ts` | 1 | 6 | 하늘섬 과거 실전, 루피 당시 7축 부재로 수치 비교 유보 |
| 합계 | **18** | **62** | 전체 사용 흐름 포함 |

기존 Factor confidence 분포는 **confirmed 26 / supported 25 / unclear 11**(등록 데이터 문자열 정적 점검). `confirmed`는 해당 요인 근거의 기존 분류이며 작가 공인 승률 또는 장면 전수 직접 판독을 뜻하지 않는다.

## 이 변경이 제공하는 것

1. **가정과 실제 교전의 조건을 구분:** 요인 영역에 저장된 대진의 전장·준비·시작 상태·외부 개입 가정을 네 칸으로 즉시 표시. 개별 전투 자료의 실제 다자전·목적·환경·제약·외부 개입은 별도로 표현한다.
2. **요인 근거 추적:** 현재 Evidence 저장소의 ID를 통해 실제 원작 인덱스/보조자료/커뮤니티 출처 구분, 출처 참고값, Evidence **Fact**, 연결 Battle의 제목·구조·목적·환경·제약·외부 개입, Evidence 자체 불확실성을 표시한다.
3. **정보 위계 보존:** 요인의 **요약·조건·불확실성은 펼치지 않아도 모두 보임**. 추가 원전 정보만 각 카드의 `details/summary`로 확인. 사용자의 열람 의사가 없는 카드까지 장문의 전투 문맥을 펼쳐 레이아웃을 늘리지 않는다.
4. **누락의 정직한 표기:** ID 또는 Battle 연결이 없는 경우 추측으로 출처를 만들지 않고 '연결 확인 필요' 및 오류 상세를 표시한다. 자동 테스트에서 기존 18건의 링크를 확인한다.
5. **역사적 특례 및 임의 비교 보호:** 하늘섬 루피의 당시 점수를 새로 만들지 않음. 등록 대진이 없는 조합은 기존처럼 스탯만 보여주고 상성 요인을 생성하지 않음.

**원작 직접성:** `source.type='canon'`은 저장소의 기존 '원작 인덱스' 분류이며, 이번에 만화 원문 컷을 직접 검토했음을 뜻하지 않음. Factor가 참조하는 자료의 실제 전장 조건과 사이트의 기본 중립 가정이 달라도 출처 내용을 바꾸지 않는다.

## 예상 주요 검증

- **정합성:** 18개 Matchup/62 Factor의 원래 Evidence IDs가 최신 현재 Evidence와 Battle로 연결되는지; 누락값을 허위 사실로 대체하지 않는지.
- **UI:** 중립/특수 조건 요약, 원작 인덱스·Fact·전투 맥락 열람, 키보드로 접근 가능한 `summary`, 소형 모바일 배치.
- **회귀:** 등록 대진 빠른 선택/좌우 교환/상태·시점 전환/랜덤, 미등록 조합 보류, 루피 2개 조건부 및 에넬 역사 사건 수치 차단.
- **검증 구분:** GitHub CI/TS/Vite 빌드와 실제 브라우저/기기 수동 시각 검사, 원작 원문 내용 검증은 각각 별도.

## 릴리즈 경계

현재 기능 브랜치에서는 기존 앱 버전 `0.4.34`를 임의로 덮어쓰지 않는다. PR 검증 후 정식 `v0.6.0` 릴리즈 범위(추가 Matchup factor의 실질 콘텐츠 검토 및 시나리오 UX 포함 여부)와 버전 승인을 별도로 판단한다. 이 PR의 UI 기능을 병합하더라도 **v0.5 검토 233축 보류**는 그대로 유지된다. 롤백은 기능 브랜치 PR의 revert만으로 충분하다.
