# v0.1.64 — 전체 캐릭터 전투 설명 무결성 검토 및 확정 오류 수정

**기준:** `main@dbd20ffc0fe7123f16d4c50ffd553b003506fcad` / v0.1.63.  
**요구:** 후속 패치를 진행하고, 각 캐릭터의 프로필·전투 설명·근거·상대·전투 장소·능력·Haki 주체가 올바른지 확인하여 틀리거나 다른 캐릭터의 설명이 섞인 경우 교체.

## 1. 검토 범위와 확인 수준

- **기계적 전수 검증 대상:** Character Master **60명**의 인물 설명 및 CombatProfile 구조, 대표 **59명 × 7축=413개**와 시점별 전체 **62 Evaluation / 434 Stat**의 `rationale`·Evidence 연결, 전체 Evidence의 subjectCharacterId·Battle ID 존재, 신규 와노 **17명 × 7개 notes =119축**, 이에 대응하는 상세 Battle/Evidence, 가중치·매치업 회귀.
- **사람/모델의 의미 검토:** 핵심 전투 설명·비교군·오염 위험 표현을 집중 대조하고, 공식 ONE PIECE.com 에피소드·프로필·원작 장면 표기와 상충하는 명백한 진술을 교정.
- **검증 경계:** 자동 검증은 **글의 참·거짓을 자동 판정하는 원작 독해기**가 아니다. 공식 애니메이션 시놉시스는 보충 출처이며, 원작 **60명 × 모든 인용 만화 컷 전수 수작업 확인은 완료하지 않았다**. 불확실한 정량 점수·작중 효과를 새로운 사실로 바꾸지 않음.

**연쇄 연결:** 와노 17명의 프로필 설명은 `wanoSeeds.fact/context/style`을 참조하고, 자동 생성 전투 Evidence도 같은 Seed를 참조한다. 따라서 Seed의 사실·판단·시점 변경은 카드와 평가 해설에서 **동일 원본으로 파생**되며, 자세한 전투 사건 문서는 `wanoCombatEvidence.ts`에서 별도로 맞췄다. 다른 인물의 `fact`을 복제해 페이지 원 점수를 올리는 구조는 아니다.

## 4. 설명 검증 전략 / 회귀 위험

- 새 `v0164NarrativeIntegrity.test.ts`는 60개 Character/434개 Stat에 대해 설명 공백, 타 캐릭터 Evidence ID 오연결, 존재하지 않는 Battle, 17×7 Wano 행 누락, 페이지 원 패왕색의 출처 일관성, 키드전 엘바프 장소, 카와마츠/킨에몬/드레이크 이력, 모든 기존 산식·59명·15 Matchup/Raw 총합 불변을 검증한다.
- **실제 수정 범위:** `src/data/sample/wanoSeeds.ts`, `wanoCombatEvidence.ts`, `wanoExpansion.ts`의 원문·실전 조건·시점 문장만 수정. `evaluations.ts`, `score.ts`, 7축 모델, 실제 Character Master ID, Evidence IDs·숫자·상태·매치업·UI·저장/복원 구조는 변경하지 않음.
- 정상 설명에 등장하는 **상대 캐릭터의 이름은 오류가 아님**. 오류는 상대 공격을 내 것이라고 기술하거나, 다른 사건의 장소/원인/전술을 내 평가 근거로 사용한 경우다. 기계 검사로 모든 의미 오류를 배제했다고 주장하지 않는다.
- 다음 **정량 패치**는 비스타 Ch.561–562/574 실제 컷과 동일축 피어 효과를 대조하고 구체적 후보 Base/Raw/Final 및 전체 파생 영향표를 산출해 소유자 승인을 받은 뒤 시행한다.
