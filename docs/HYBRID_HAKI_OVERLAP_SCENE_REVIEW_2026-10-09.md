모두 `src/data/sample/hybridRawPilotReviews.ts`에서 `cross-stat-overlap-unresolved` 상태인 **기존 Raw**다. 공격/방어/판단 등 각 축의 관찰된 Base 성과는 부정하지 않는다.

**진짜 결론:** 6건 모두 *감점 확정*이 아니라 **독립적인 Raw 효과가 아직 입증되지 않은 점검 대상**이다. 이들 중 일부는 실제로 다른 결과를 설명할 수 있다. 1개 장면이 2개 스탯 근거로 유효한 것과 2회 Raw 가산할 권한은 다르다.

## 3. 계산에 넣어본 세 가지 다른 가정

### A. 실제 현재 공식 Draft Baseline

`Final = min(100, Base + 0.5 × typed Raw)`. Raw 53건/총 256, 39개 Evaluation을 그대로 사용한다.

### B. 4개 일반 Haki Base 이관 (앞선 PR #27)

사카즈키 Defense, 쿠잔 Attack·Defense, 카타쿠리 Attack의 현재 유효 Raw 12를 Base +6으로 수학적으로 이관한다. **후보만 존재**하며 39개 Final/Overall 모두 Baseline과 동일하다. 다른 Haki Weight에선 결과가 달라져 Version 재승인이 필요하다.

### C. 6개 **미검증 다축 Raw 제거 스트레스** (이번 신규 코드)

`src/domain/evaluation/hybridOverlapStress.ts`는 6건의 Raw(4+4+4+6+4+6 = **28 Raw**)만 **일시적으로 제외하고 Base는 변경하지 않은 채** 39개 Evaluation 전부를 재계산한다.

- **Raw 합계 256 → 228(실험에서만)**, Raw-positive 항목을 보류하는 진단용 제약 시나리오다.
- Base를 맞춰 주지 않았으므로, 실제로 유효했던 패기 기여까지 빠져 **과소평가될 수 있다**. **따라서 이것은 정확한 점수의 하한이나 정식 재산정 결과가 아니다.**
- 해당 6건의 승인/부정이 의미 있게 바꿀 수 있는 스탯과 Overall을 *보여주는 것*만 목적이다.

| 대상 | Legacy Overall | 스트레스 시 Overall | 변화 | 영향 근거 |
|---|---:|---:|---:|---|
| **쿠잔** | 92.714 | **92.429** | −0.286 | Technique 93→91 |
| **샹크스** | 92.571 | **92.000** | −0.571 | Technique 96→92 |
| **카타쿠리** | 82.714 | **82.000** | −0.714 | Technique 86→83, Combat IQ 83→81 |
| **링링** | 94.286 | **93.857** | −0.429 | Technique 94→91 |
| **사카즈키·미호크 등 나머지** | 변경 없음 | 변경 없음 | 0 | 선정된 6건 이외 데이터 불변 |

정량적 순위 민감도 (전체 **39개 평가 시점**, 동점은 정렬 방식의 영향을 받음):
- 샹크스: 12번째→15번째; 쿠잔: 10번째→12번째.
- 카타쿠리: 23번째 유지; 링링: 7번째 유지.
- 사카즈키·쿠잔은 실험상 정확히 **Overall 동점(647/7)**. 이것이 원작 1대1 결과를 부정하는 것은 아니다.
- 미호크보다 샹크스의 Overall이 떨어져도, 이는 **같은 원작의 다른 추론 가정을 적용한 결과**이지 실전 승률 계산이 아니다.

**15개 직접 Matchup의 factor, evidence, winner prediction(원래 없음)은 전혀 수정하지 않는다.** 특히 `matchup-mihawk-shanks`, `matchup-akainu-kuzan`, `matchup-kaido-linlin`, `matchup-garp-current-kuzan`, `matchup-jozu-kuzan`는 영향 캐릭터와 연결되지만, 별도 비공식 수치 시나리오를 기존 상성 Evidence에 덧씌우지 않는다.

## 4. Feature request — FEATURED 시나리오 선택 표시

- 클릭 즉시 선택된 대진은 **어두운 배경·강한 테두리·✓ 마크**로 표시. 스크롤 가능한 기존 가로형 UI 유지.
- 좌우 SWAP에도 같은 대진이면 선택 유지.
- 로스터 수동 변경, RANDOM으로 바뀐 대진이 Featured에 없으면 기존 표시 해제.
- 캐릭터의 **평가 시점**이 달라 현재 직접 Matchup에 해당하지 않으면 표시 해제하고, 원래 시점으로 복원 시 다시 활성화.
- 중복된 별도 local selected-ID state를 만들지 않는다. 키보드 `:focus-visible` 링 및 `aria-pressed`로 가시성과 접근성 제공.
- `src/ui/pages/MatchupHome.test.tsx`: 첫 화면, Featured 클릭, 다른 Featured 전환, SWAP, 수동 로스터 변경, 상태 전환/복원, RANDOM의 표시 동기화를 실제 React/jsdom에서 검증.

**의미 한정:** 이는 이미 구현되어 있는 **FEATURED 빠른 대진 선택 버튼**에 선택 표시를 추가하는 것이지, 아직 PROJECT_SPEC가 후속 후보로만 정한 Terrain/Distance/Preparation의 새로운 별도 시나리오 생성 기능은 아니다.
