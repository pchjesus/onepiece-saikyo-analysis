# v0.1.62 — 승인된 다축 Haki 중복 정리와 샹크스·비스타 상향 가능성 검증

**기준:** v0.1.61 main `75cb8e19a2a20b182f9dd634bc3715b2023fd335` (2026-10-10).  
**사용자 결정:** 캐릭터 Overall 패치를 허용하며, **샹크스·비스타에는 가상 Overall 감점안을 적용하지 않고 오히려 상향 근거를 탐색**한다. 원작 사실·전투 조건·해석·프로젝트 점수·커뮤니티 반응은 구분한다.

## 1. 다축 심사 기준 및 결론

승인된 Hybrid/Exceptional Haki 기준에 따라 (1) 패기 사용 사실, (2) 예외적으로 높은 응용, (3) 관찰된 Base 성과에 포함되지 않은 **독립적인 추가 효과**가 모두 구분되어야 양(+) Raw를 별도로 유지할 수 있다. 같은 Evidence를 공격·방어의 서로 다른 **관찰 결과**에 사용할 수는 있으나, 같은 공격을 Base와 패기 Raw로 두 번 산정하는 것은 허용하지 않는다. 이번 수치 변경은 '근거가 부족하니 전부 0'이 아니라 **현재 Base가 이미 같은 사건의 동일 효과를 계산한다는 적극적인 중복 판정**에 한정한다. 이는 공식 전투력 점수가 아니라 프로젝트의 판단이며 원본 만화 컷 전수 검증은 별개로 남는다.

| 대상 / 축 | 이전 Base + Raw = Final | 변경 Base + Raw = Final | 중복 배제 이유 |
|---|---|---|---|
| 킹 Attack | 83 + 4×0.5 = 85 | 83 + 0 = **83** | 같은 Ch.1032 검 격돌·조로전 공격 위협이 이미 Attack Base83의 검격에 포함됨. 패기만의 별도 예외 공격을 분리하지 못함 |
| 킹 Technique | 80 + 2×0.5 = 81 | 80 + 0 = **80** | 검에 무장색을 결합하는 통상 운용을 Base80의 검술과 중복 계수함; 루나리아 Flame ON/OFF·화염은 별개 기술 |
| 징베 Attack | 76 + 4×0.5 = 78 | 76 + 0 = **76** | Ch.1018 후즈후를 격파한 어인공수도 타격이 Base76에 포함됨; 별도의 무장색 예외 증폭 타격이라고 특정할 증거 없음 |
| 카타쿠리 Combat IQ | 82 + 4×0.5 = 84 | 82 + 0 = **82** | 같은 미래정보를 활용한 선제 판단을 Base82와 Raw4로 반복 계산. 정보 취득 그 자체는 별개의 추가 전술 판단 결과가 아님 |

- **유지한 Raw:** 징베 Defense4(후즈후에 대한 경화 방어와 빅맘 순간 차단은 Attack 최종타와 **별도의 방어 효과**), 카타쿠리 Defense6(미래예지 선행회피)과 Technique6(예지·부분 모치 변형의 정밀 연동). 이 유지 판정은 정량적 한계효과의 완전한 인증은 아니며 v0.1.63의 원작 컷 검증 대상.
- **수치 불변:** 샹크스, 비스타, 나머지 56명, 카이도 Defense100, 전원 E1/E2/E3, Haki Weight 0.5·Balanced v1.2, Evidence ID/원작 출처, 직접 Matchup 15건과 UI·저장/복원은 그대로 둔다.
- **능력 보유와 Raw를 혼동하지 않는다:** Raw0이 되었더라도 킹·징베의 무장색 보유·원작 적용 기록을 제거하거나 부정하지 않는다. 기존 Evidence 사실·ID·stat-role 유지, 평가 해석만 새로운 Base/Raw 판정과 일치하도록 수정했다.
- **유보:** '숫자를 감점해야 하므로 Raw0'가 아니라, 네 축의 기존 양수 Raw **해당 항목 전체가 동일 Base 성과의 중복분**이라는 이유로 제거했다. 특정 공격력의 정답을 공식 설정이 수치로 제공한다는 뜻은 아니다.

### 공식·원작 근거와 역할
- ONE PIECE.com **TV1112** (Ch.1079에 대응): 산하 함대가 전자기포 공격으로 파괴될 미래를 감지 → 단독으로 키드의 배에 접근 → '카무사리' 한 차례로 키드/다무드 펑크 제압. **이후 함선 파괴의 주체는 도리·브로기**. 미래 감지는 Observation, 실전 접근은 Speed, 패기 강화 검격은 Attack, 목표·시간 선택은 IQ에 각기 다른 *의미*를 가질 수 있다. 단, **이유가 하나인 일격 결과를 여러 Raw의 별도 증분으로 곧장 환산하지 않는다.**
- ONE PIECE.com **TV1082** (Ch.1055 대응): **멀리 떨어져** 로쿠규에게 강한 패왕색을 보내 압박, 로쿠규가 철수. 이는 키드 타격과 다른, **독립된 패기 압박·상대 행동 변화** 사례이며 단순 검격 Attack가 아니다. 전장에 다른 변수(로쿠규가 아카자야·모모노스케와 교전 중, 빨간 머리 해적단 위협) 있음.
- ONE PIECE.com **공식 샹크스 프로필**: 사황, 정상결전 개입·전쟁 중지. 명성/현상금/종전을 독자적인 1:1 Attack 보너스로 세지 않는다. 마린포드 아카이누의 코비 공격을 차단한 Defense 관련 근거도 기존 점수에 이미 반영.

### 상승 가능 축(동일 사건 재사용 방지)
1. **Versatility 88 상향 검토:** 키드전의 단일 목표 검격과 달리 **원거리 패왕색 압박(로쿠규)**이라는 별개 전술 효과가 반복 가능한 고급 역할 확장인지 심사. 현재 Versatility Base88의 일반적인 패기 원거리 투사가 이미 포함되었다면 **중복**이다. 새로운 숫자 앵커 없음.
2. **Combat IQ 93 상향 검토:** 상대의 함대 공격 미래를 파악해 보호 대상을 선택한 선제 전략. 다만 Base91과 견문Raw4가 이미 사건을 공유하므로 **더할 새로운 독립 장면**이 없으면 상향 불가.
3. **Attack97·Technique96 추가 상향 가능성:** 미호크(검술)와 대조할 때 샹크스의 패왕색 검격과 견문 정보의 연계는 무기술 전문성과 다른 능력이다. 그런데 현재 Raw는 이미 상당한 수준이고 **Attack/Technique IQ 각각에 독립 성과를 추가 확인하기 전 +N 적용은 보류**.
4. **Speed95(E3)**: TV1112의 매우 빠른 접근이 명시되나 미래정보의 선행 경고와 순수 기동속도를 구분해야 한다. 출처 자체의 직접성·반복 표본이 부족한 상태에서 무작정 상승 금지.

**판정:** 직접적인 '상향 심사 대상'을 유지. **추가 +점이나 Overall 상승 적용은 이번에 하지 않음**. 새로운 장면별 역할 분해와 동일 축 앵커가 필요한 상태다. '견문살해/미래예지 봉쇄' 같은 2차 팬 설정은 현재 확인한 공식 교전 근거에 없으므로 점수에 추가하지 않는다.

## 4. 비스타: 상향 가능성 심사(숫자 상향 확정 아님)

- **공식 제작 뉴스** (2021-02-20)는 비스타가 정상전쟁에서 미호크와 실제 검을 주고받았음을 다시 확인한다. 현재 Technique Base86/Final87(E1)은 미호크 Technique99(E1)와 12점 차이며, 서로 다른 출처 강도·전투 시간·제한을 감안하더라도 **기술력 상향 검토의 직접 출발점**이 된다.
- **상향 우선축 — Technique87:** 짧은 교전에서 공방 지속, 이도류 숙련, 미호크 검술 대응 방식, 실질 상처/상대 부담 등을 Ch.561–562의 원본 컷으로 검증해 미호크/조로와 *전술·검술 차원* 비교. **원작 직접 컷·전투 의도·교전 길이 미확인 상태에서 +N 제안 보류**.
- **상향 차순 — Defense79 / Attack82:** 미호크의 참격에 대응한 **방어 기동**과 아카이누 상대 **공격 적용**을 별개 사건으로 비교. Ch.574는 마르코와 합동이며 지속적인 아카이누 손상이 불명확하므로 검격 1회를 미호크급 Attack으로 과대평가하지 않는다.
- **Haki Raw Attack4/Technique2:** 무장색을 사용했다는 확인과 *예외적인* 무장색 효과를 구분해야 한다. 상향 근거의 중심은 **공식 검술 실적(Base를 재평가할 여지)**이지 무장색 Raw 일괄 확대가 아니다. 기존 값 보존.
- **대조군:** 미호크 Technique99 vs 비스타 Technique87 vs 조로 Technique87, 킹 Technique80(패치 후). 서로 다른 시점·조건이므로 연전 시간·상대 전력/의도를 직접 확인하기 전 자동 동급·자동 점수 상승은 금지.

**판정:** 비스타 Technique 상향 **우선 심사**, Attack/Defense 조건부 탐색. **+점 및 Overall 증가는 현재 확정하지 않음**. 기존 점수·원본 Evidence·Raw 보존.

## 5. 나머지 다축 판정과 보존 사유

- **킹:** Ch.1032 무장색 검 충돌의 공격·기술 두 Raw를 **둘 다** 검격 Base에 흡수된 동일 효과로 판정; 별도 증분 0. Defense88 루나리아 상태 성과는 건드리지 않음.
- **징베:** Ch.1018 Attack은 공수도 타격 Base가 이미 포괄. **Defense의 무장 경화와 상대 손가락 손상은 별도 기능이며** 빅맘 Ch.890도 방어 맥락 제공. 방어 Raw4의 크기가 검증됐다는 뜻은 아니며 이후 비교 필요.
- **카타쿠리:** TV857은 견문색을 통한 **미래예지와 신체 변형으로 효율적 회피**를 직접 설명한다. 이 방어 작동(Defense Raw6)과 모치 정밀 제어(Technique Raw6)는 현재 별개 심사 가설로 유지하되, **IQ Raw4는 선제 판단 Base82와 동일 결과를 중복**하여 제거. 스네이크맨에 대한 실제 대응과 선행 정보의 실효가 한계 없는 Speed 보너스는 아님.
- **샹크스:** 원거리 패왕색 압박(Ch.1055)과 키드전 기동·타격(Ch.1079)의 **서로 다른 사건/기능**을 강점으로 인정. 다만 Technique의 패왕/견문 각 Raw4, IQ의 견문Raw4, Attack 패왕Raw6이 특정 출력과 결정을 중복 계수했는지 **미해결**, 임의 감점이나 신규 보너스 없음.
- **비스타:** 미호크와 제한적 검술 공방과 아카이누에 대한 합동 공격은 각각 기술과 공격을 보여준다. 상향을 위해 필요한 원본 근거는 **Technique의 실전 비교**이며, 두 Raw를 다른 축에서 동시에 증가시키지 않음.

## 6. 기술 영향·테스트·버전

- `evaluations.ts`: **킹 Attack/Technique, 징베 Attack, 카타쿠리 IQ만 Raw 제거**, 나머지 모든 413 대표 축 Base 및 Raw 불변. 3개 Evaluation의 `evaluationDataVersion`을 `evaluation-0.1.62-haki-independent-review`로 갱신.
- `evidence.ts`: 대상 3개 사건의 `interpretation/evaluationImpact` 중 점수 연계 문구를 신규 Base/Raw 판단에 맞게 정정. Evidence ID, 원작 source reference, fact, 연결, 전투 기록은 변경하지 않음.
- `hakiMultiaxisCalibrationV0162.test.ts`: 네 축의 앞뒤 수치, 새 Overall과 상대 위치, 샹크스·비스타 완전 불변, Haki 분리와 Character/Evidence/readiness/Matchup 15·계산 모델 보존 검증.
- 기존 구 버전 **현재 평가 연동 테스트**는 새 승인 패치 수치에 맞게 갱신하되 역사적 문서의 구 버전 데이터는 삭제하지 않는다. 이전 v0.1.61 문서의 샹크스·비스타 가상 감점표를 현재 의사결정 근거로 **사용하지 않는다**.
- 테스트, 빌드, 병합, Pages 배포는 각 실행의 정확한 커밋 SHA에 대한 실제 결과로 최종 보고한다.
