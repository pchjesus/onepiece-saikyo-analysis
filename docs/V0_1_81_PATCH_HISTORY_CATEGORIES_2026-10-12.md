# v0.1.81 — 패치 내역 카테고리 및 표시 간소화

**기준 버전:** v0.1.80 / `main@d6325491a3fdf0acea9d4e685c78bcc0f6cb928d`  
**패치 종류:** UI·기능 개선. PROJECT_SPEC.md 및 전투력·근거 데이터는 변경하지 않는다.

## 변경 내용

| 카테고리 | 분류 기준 | 사용자에게 보이는 정보 |
|---|---|---|
| **스탯 조정** | `kind: score` | 캐릭터와 조정 대상 축, 변경 전/후 점수, 변경 이유, 관련 근거 링크 |
| **캐릭터·소속** | `kind: character | group` | 추가·소속 변경 내역, 확인된 설명과 관련 출처가 있을 때 링크 |
| **UI·기능** | `kind: feature` | 추가·수정된 기능. 전투력 근거는 필요하지 않으며, 설명·이유는 선택 |
| **근거·분석** | `kind: evidence` | 공식 근거 및 전투 맥락 검토, 수치 유지 판단과 그 이유 |

### 사용자 조작

- 상단 **패치 내역** 버튼을 클릭해 버전 기록을 연다.
- **전체 / 스탯 조정 / 캐릭터·소속 / UI·기능 / 근거·분석** 5개 필터 중 하나를 선택한다.
- 해당 카테고리의 기록이 있는 버전만 표시하며, 한 버전에 여러 카테고리가 있으면 **카테고리 제목으로 구분**해 보여준다.
- 각 필터 버튼은 전체 이력 기준 등록 건수를 표시한다. 필터는 화면상의 표시만 변경하며 점수·랭킹·계산 로직에는 영향을 주지 않는다.
- **v0.1.80 '패치 내역 버튼 추가'** 항목은 이름만 표시하고 부가 설명·변경 이유·전투 근거는 나타내지 않는다. 다른 UI 항목의 설명도 데이터에 존재할 때만 표시한다.
- **스탯 조정** 항목의 실제 전후 수치와 사유·원문 링크는 그대로 보존한다. v0.1.79 퀸 Versatility 80→82, v0.1.77 코비 Combat IQ 76→72 및 그루스 Versatility 85→80, v0.1.76 코비 Attack 82→77 등이 여기에 해당한다.

## 구현 구조

- `src/data/patchHistory.ts`: `PATCH_CATEGORIES`, `categoryForPatchChange`, `PatchCategoryFilter`와 새 버전 이력을 단일 소스로 선언. `detail` 및 `reason`은 선택값으로 허용하되 스탯 조정 근거의 필수 보존은 테스트에서 검증한다.
- `src/ui/components/PatchHistoryDialog.tsx`: 필터 상태, 버전 및 카테고리 그룹 표시, 누락 정보의 비표시. 기존 닫기 버튼·Escape·배경 클릭·포커스 복귀 동작 유지.
- `src/ui/styles.css`: 모바일에서 가로 스크롤할 수 있는 분류 버튼과 섹션 제목 스타일 추가.
- `src/ui/App.tsx`: 버튼에 표시할 최신 버전은 `patchHistory[0].version`에서 읽어 코드와 이력의 버전 불일치를 방지.

## 검증 범위

- 데이터 단위 테스트: 모든 변경 `kind`가 정확히 하나의 카테고리에 속하고, 모든 **스탯 조정은 전후 수치 및 사유**를 유지하며, '패치 내역 버튼 추가' 항목에 설명·사유가 없는지 확인.
- UI 통합 테스트: 필터 전환, 표시 건수, 스탯/캐릭터/분석 분리, 전체 초기화, v0.1.81 최신 버전 표시, 기존 모달 닫기.
- 회귀 확인: 기존 70명(69명 대표 평가), 72 Evaluation, 504 Stat, 88 Membership, 15 Matchup, Haki Raw, Balanced 1.2 결과 불변.
- GitHub Actions 테스트 및 Pages 배포의 최종 SHA 일치는 릴리즈 확인 시 별도 기록한다.

**주의:** 이력은 검증 가능한 v0.1.75~v0.1.81 범위만 다룬다. 이전 릴리즈의 누락된 상세 데이터를 추정·창작해 채우지 않는다.
