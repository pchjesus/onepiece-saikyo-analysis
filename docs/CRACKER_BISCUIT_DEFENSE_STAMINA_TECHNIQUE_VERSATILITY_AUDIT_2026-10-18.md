## 3. 양방향 심사

### Defense82 / E2 — 잠정 유지
- **과대평가**: 비스킷 갑옷/방패가 버틴 공격을 본체 피부의 절대 내구성으로 복제하거나, 물에 젖어도 동일 성능이라고 가정하면 오류다.
- **과소평가**: 프로젝트 Defense는 맨몸 내구 전용 축이 아니다. 자신이 생성한 갑옷·방진으로 공격을 실제 차단하고 본체에 닿지 못하게 하는 것은 **개인의 실전 방어 능력**이다.
- **판정**: 현행 82는 조건을 묶은 시스템 방어 Draft로 설명 가능. 건조/강우 조건은 구별하되 상태별 수치를 자동 신설하지 않는다.

### Stamina82 / E2 — 잠정 유지, 지속 강도 추적 필요
- **과대평가**: 11시간 소환전을 11시간 직접 피격·근접 격투의 피로저항으로 바꾸면 안 된다. TV805는 크래커의 실제 지친 모습도 설명한다.
- **과소평가**: 생성·조종을 장시간 계속하는 능력 운용도 실제 전투 지속 성과다. 본체가 직접 맞지 않았다는 사실로 이 성과를 삭제하지 않는다.
- **판정**: 82 유지 가능. 잭88(교대 상대가 있는 5일 전선), 퀸83(마르코 피격 후 상디 교전), 카타쿠리85(직접 장시간 결투)는 **전투 구조가 달라 단순 시간 비례 계산 불가**.

### Technique83 / E2 — 잠정 유지, 교차 비교 우선
- **긍정**: 갑옷/방패/병사 형성, 본체 은닉, 다수 부대 반복 생산·원격 배치, 본체 검술까지 전투에서 연계했다. **하나의 열매여도 정교한 군체 운용 숙련은 높을 수 있다.**
- **과대평가**: 병사 수·생성 횟수를 정확한 독립 수동조작 수나 정밀도 자동 보너스로 바꾸지 않는다. 수분 상성 노출 후 다른 대응을 입증하지 못한 한계도 분리한다.
- **과소평가**: 장비·기전 종류가 적다고 군체 제어의 질을 무시하지 않는다. Technique는 시스템 수보다 **실제 운용의 정밀도**가 중요하다.
- **앵커**: King83(상태별 비행·검·불꽃), Queen80(다중 무장과 오발), Smoothie84(능력 흡수·상태제거·강화)와 **동일한 조작 난도·정확성·안정성 기준**을 비교할 후속 과제. 83을 그대로 유지하되 숫자 확정 판정은 아니다.

### Versatility80 / E2 — 잠정 유지, 공유 약점 보존
- **긍정**: 방어·다수 공격·상대 소모·본체 은폐·본체 검격은 서로 다른 전술 목적/역할이다. 한 열매에서 파생돼도 유효한 역할을 모두 삭제하지 않는다.
- **과대평가**: 갑옷·병사·검·방패를 각각 독립 작동 시스템으로 셈하지 않는다. 대부분 비스킷이라는 공통 약점에 영향을 받으며 TV805의 물 상성에 대응할 새로운 효과는 미확인이다.
- **과소평가**: 본체 검술과 다수전 방진, 공격·방어·은닉의 전환은 실제 수행되었다.
- **앵커**: Marco88(비행·회복·보호·감염 억제), Queen84(고대종·개조·조건부 역병탄), Smoothie82(흡수·독 제거·거대 참격), Jack74(근접/매머드와 병력 투입 분리). Cracker80은 **여러 역할 + 공통 수분 취약성**이라는 현행 평가와 양립한다.

### 다른 세 축도 과대/과소 양방향 유지
- Attack78(E2): 본체의 Gear4 루피 팔 검격을 병사 공격/무장색 Raw로 복제하지 않는다. 근접 유효타 자체는 보존.
- Speed75(E3): 병사의 반응/속도를 본체 최고 속도로 환산하지 않되, 본체 직접 교전의 일부 성공도 무시하지 않는다.
- Combat IQ77(E2): 은닉과 소모전 선택의 실적과 물 상성 노출 후 대응 한계를 함께 고려. 나미 개입 전투 결과만으로 지능 부재를 단정하지 않는다.

## 4. 사용자 보충 원칙과 후속 검증표

**원작 실적 하나에서 서로 다른 축의 합리적 상승 가능성을 추론하는 것은 허용된다.** 별도 전투 장면을 각 축마다 반드시 요구하지 않지만, 능력/결과/추론/숫자 관계를 적어 같은 결과를 4개의 독립 보너스로 계산하지 않는다.

| 전투 조건 | Defense 평가 의미 | Stamina 평가 의미 | Technique 평가 의미 | Versatility 평가 의미 |
|---|---|---|---|---|
| 건조한 비스킷 방진 | 차단·본체 접근 방해 | 반복 생산 지속 | 형태/부대 운용 정확성 | 공격/방어/은닉 역할 |
| 나미가 강우한 구간 | 방진 연화와 성능 저하 | 생산 지속 **+ 피로 한계** | 제작 반복과 상성 대처 제한 | 여러 용도에 공유되는 수분 약점 |
| 본체 직접 검격/피격 | 본체 방어 별도 표본 | 피격 후 지속 자료 별도 판단 | 본체 검술 연계 | 병사와 직접공방 전환 |
