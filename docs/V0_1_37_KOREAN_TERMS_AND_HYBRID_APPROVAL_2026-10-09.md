## 3. 근거가 충분한지 판단한 결과

### 강하게 지지되는 사실과 통상 Haki → Base 후보 4건

- 사카즈키·쿠잔의 정상결전 삼대장 **공동 방어**는 실제 관찰 성과이지만 **독립적인 특출난 무장색 +N**을 입증한 것은 아님.
- 쿠잔의 가프 상대 Ice Glove 근접 공방 역시 **공격 성과는 사실**이나 그 타격 내 패기 자체가 Base와 분리된 +N을 낳았는지는 검증되지 않았음. 시류의 가프 부상 등 전투 조건 분리.
- 카타쿠리의 루피 상대 무장색 공격은 **실제 성과**이나 통상적으로 통합되는 패기의 추가 한계효과는 별도 증명되지 않음.
- 따라서 4건은 패기의 부재가 아닌 **관찰된 실제 성과를 Base에 반영하는 방식의 분류 변경**을 제안할 수 있음. 기존 Final의 **절대 점수 정당성을 새롭게 확정한 것은 아님**.

### 아직 숫자 가산 증명이 부족한 6건

- 샹크스 카무사리: Ch.1079 및 [공식 1112화](https://one-piece.com/anime/67527/index.html). 미래 피해를 인지·선제 대응·타격 적중, 도리·브로기의 배 파괴 구분. 한 회피/타격에 Technique 패왕색+견문색 Raw를 각각 가산할 **독립 정량 효과 미확정**.
- 카타쿠리 미래예지: Ch.881–884 및 [공식 857화](https://one-piece.com/anime/o4869/index.html). 침착함→미래 인지→모치 변형→회피. Defense와 Technique/전투 지능을 분리해 추가 점수화할 직접 비교는 미충족.
- 링링 페이지 원 상대 패기 공격: Ch.1011 및 [공식 1031화](https://one-piece.com/anime/o6229/index.html). 패기 실린 근접타격은 확인되지만 Attack과 별도로 Technique에 +3 최종점수를 더할 근거는 미충족.
- 쿠잔 Ice Glove: Ch.1087 및 [공식 1121화](https://one-piece.com/anime/69144/index.html). 한 권격을 Attack·Technique에 각각 추가 가산할 독립 결과 미충족.

**판정:** 6건은 예외적 응용의 강함을 부정하지 않는다. 다만 **독립한 +N 보너스를 그대로 두기 위한 근거**는 아직 충분하지 않다. 따라서 이 건들의 Final 감소(+N 삭제 후 Base 방치)는 **원작 기반 확정 재평가로 추천하지 않음**.

## 4. 실제 수치 재산정 후보 — 코드로 검증할 2개 방안

`Final = min(100, Base + 0.5 × 패기 원점수)`.
본 시뮬레이터는 **score-invariant rebase**이다. 변경 후 **Base에 유효 패기 성과 포함**, 선택한 Raw만 0; 근거없는 자동 +N도 새 감점도 없음.

| 평가 축 | 기존 기본점수 / 원점수 → 최종점수 | A: 4건만 재분류 | B: 중복 위험 6건까지 재분류 |
|---|---|---|---|
| 사카즈키 방어력 | 94 / 2 → **95** | 95 / 0 → **95** | 95 / 0 → **95** |
| 쿠잔 공격력 | 91 / 4 → **93** | 93 / 0 → **93** | 93 / 0 → **93** |
| 쿠잔 방어력 | 92 / 2 → **93** | 93 / 0 → **93** | 93 / 0 → **93** |
| 쿠잔 기술·숙련도 | 91 / 4 → **93** | 유지 | 93 / 0 → **93** |
| 샹크스 기술·숙련도 | 92 / 8 → **96** | 유지 | 96 / 0 → **96** (2개의 Raw 기여) |
| 카타쿠리 공격력 | 79 / 4 → **81** | 81 / 0 → **81** | 81 / 0 → **81** |
| 카타쿠리 기술·숙련도 | 83 / 6 → **86** | 유지 | 86 / 0 → **86** |
| 카타쿠리 전투 지능 | 81 / 4 → **83** | 유지 | 83 / 0 → **83** |
| 링링 기술·숙련도 | 91 / 6 → **94** | 유지 | 94 / 0 → **94** |

- **A:** 4 Raw 기여를 4개의 스탯 Base에 이관. 53 typed Raw / 합계 256 → **49건 / 244**. 기존 39 평가 Final/Overall과 매치업 결과 변화 0.
- **B:** 합계 **10 typed Raw**(A 4 + 중복 위험 6)를 9개 스탯 Base에 이관. 원점수 256→**216**, Typed Raw 53→**43**. 39 평가 Final/Overall·기본 순위·매치업 변화 0.
- 양쪽 모두 코드 `src/data/sample/hybridApprovalPreview.ts`의 **독립 복제 시뮬레이션**이고, A안 4건은 `sampleEvaluations`에 실제 변경됐고 B안 6건만 미반영이다.
- 기술별 고유한 강함이 인정됐다는 사실만으로 Raw 금액을 검증했다고 주장하지 않는다. **남은 4개의 예외적 적용 Raw 역시 개별 숫자 +N의 근거 재검토는 필요**.
- **별도 계산 모델 가중치 0.0/1.0에선 같은 등급과 순위가 유지되지 않음.** 다른 모델을 지원할 때 반드시 계산 모델·평가 데이터 버전을 동시에 갱신해야 한다.

### 점수를 실질적으로 깎는 다른 가정은 미승인·비추천

기존 6 Raw 합계 **28**을 Base 보전 없이 제거하는 스트레스 실험은 [v0.1.36 감도 분석](HYBRID_HAKI_OVERLAP_SCENE_REVIEW_2026-10-09.md)에만 존재한다. 이 방식은 현재 Final의 7축 합계에서 쿠잔 −2, 샹크스 −4, 카타쿠리 −5, 링링 −3의 효과가 있지만, Haki 사용 상태를 유지한 채 Raw만 빼는 것은 **같은 실전 성과를 통째로 제거할 위험이 있어 공식 재산정안으로 추천하지 않는다**.

## 5. 사용자에게 요구하는 최종 선택

1. **사용자 승인 A(적용됨):** 직접적 근거가 충분한 통상 Haki 4건만 재분류. 중복 위험 6건과 예외적 사례 4건은 정밀 장면 검증 전까지 유지. 다른 39개 평가의 정합성 감사도 지속.
2. **확장 B:** 독립 숫자 가산이 미확인된 6건도 성과 통합(Base)으로 정리. 숫자상 강함과 순위는 유지하되, 각 Haki 유형별 Raw 분해가 가진 실험적 의미는 줄어듦.

**공통:** `main` 변경/배포 **사용자 컨펌 전 금지**, 후보의 7개 Final과 Overall 모두 유지. **만약 실제 Final 변화를 원한다면** 별도의 장면·독립 효과 비교 근거를 구체화한 뒤 캐릭터별 새 기준을 함께 승인해야 한다. 근거만으로 정확한 ±1/±2를 강제 계산하지 않는다.

## 6. 2개 후속 집단 사전 조사(아직 로스터 추가 안 함)

- 검토 우선: **혁명군**, **CP0(사이퍼 폴 이지스 제로)**. 공식 소속과 독립 전투 장면이 다수이며 현 로스터의 해군·밀짚모자 기준선과 크로스 매치업 Evidence를 확보하기 쉬움.
- 신규 캐릭터의 7개 Stat은 승인된 최신 Hybrid 기준(일반 Haki는 관찰 Base, 특출난 별도 효과만 Raw)으로 **근거→전투 조건→정량 평가** 순서에 따라 산정한다.
- 바로 3명을 억지로 채우지 않으며 각 캐릭터의 직접 Evidence, 시점, 다인전/호위조건, readiness E1–E3를 먼저 분리.
- **사용자 지시 순서 준수:** 본 승인 → 기존 브랜치 main 반영/빌드·배포 검증/보고 → 신규 2집단에 대한 다음 별도 작업 → 보고 후 사용자와 스탯 세부 조정.

**핵심:** 이 보고서가 근거 없이 기존 순위를 바꾸는 승인 요청이 아님을 명확히 하고, 수치 후보·판정 보류·호환성 조건을 분리한다.
